# 《血雾班西》线索组合与情报交易设计

版本 v1.0 · 2026-11-18 · 设计与平衡草案

本稿落实项目负责人的最新要求，定义第一幕的证据取得、条件对话、组合消耗、提示反馈、借火和金钱交涉。场景对白、收购人物与价格为新增设计草案。对应体验方向见 [第一幕交互与叙事优化建议](07_第一幕交互与叙事优化建议.md)。

## 1. 所有条件对话由线索解锁

玩家调查得到依据后，才出现与依据对应的特殊话题。原始线索与组合线索都可以提供依据。

例如，获得教堂收据后可以谈“我接过教堂的运输委托”；听船长说出格尔曼的名字和去向后，才可以在餐厅辨认并寻求他的帮助。

### 1.1 一条话题的判定顺序

1. 玩家已经亲自调查、阅读、目击或听到相应内容，线索登记成功。
2. 当前线索簿中存在该原始事实，或存在继承该事实的组合卡。
3. 当前人物处于可接触地点与时段，玩家满足必要的引荐和接触条件。
4. 校验金钱、关系、此前行为和世界状态。
5. 展示有依据的话题，玩家选择后才执行交涉。

缺少线索时隐藏话题。拥有线索但金钱不足时，可以看到已经想到的交涉方式及当前差额。完成一次情报交付后，按事实或奖励组记录结果，重复出示只获得符合情境的回应。

问候、告别、取消和打开线索簿为基础操作。人物的场景招呼可以主动发生，借此提供第一条观察线索。涉及情报、服务、请求、交易、威胁或特定人物的条件话题，都遵循线索前置。

### 1.2 原始线索与组合线索的不同作用

| 玩家掌握的内容 | 可以说的话 | 人物可要求的后续 |
|---|---|---|
| 看见一份收据 | “这份收据上写着教堂的名字。” | 询问货物、时间和是否由玩家亲自运送 |
| 收据与自己的委托记忆已经关联 | “我给教堂运过一只密封木箱。” | 询问路线与是否打开过箱子 |
| 运输记忆与教堂现场痕迹相符 | “运输路线和侧门的车辙对得上。” | 核对细节，形成有效情报 |

人物回应根据证据强度变化。组合可以组织事实、提出解释，核验继续依赖现场、证词或行动结果。

## 2. 线索详情、合并与保留的证据

### 2.1 点开一张线索卡

详情页显示名称、类型、发现地点、游戏时间、具体记录和相关人物。组合结果还显示参与推理的事实摘录、主角的判断以及尚未证实的部分。

示例卡片《教堂运输委托》可以展开以下内容。

- 事实一，收据写有风暴教堂、米勒主教和密封木箱。
- 事实二，玩家想起暴雨中的搬运，以及有人把钱塞进手中。
- 判断，自己可能参与了当天的运输。
- 待核验，具体送达路线、木箱内容与记忆空白的关系。

“相关人物”表示当前角色知道的联系。未发现的人名与后续真相随知识进度揭示。

### 2.2 两张输入卡变成一张结果卡

| 组合前 | 操作 | 组合后列表 |
|---|---|---|
| 教堂收据、昨夜的委托 | 关联 | 教堂运输委托 |
| 教堂运输委托、教堂侧门的箱车痕迹 | 关联 | 教堂运输路线的疑点 |

成功时，删除两张输入卡的列表项，创建一张结果卡。原卡片的事实、来源、已完成核验和已获得用途全部进入结果卡详情。

例如，收据被组合之后，“出示收据记录”的话题仍可用。判定需要的收据事实已由结果卡承载，详情中可以选出对应证据段落。

结果卡参与后续组合时，继续继承已有内容。若两个待关联事实已经位于同一张结果卡中，详情页提供“继续推演”，在原卡上补充新判断，列表仍保留一张卡。这样避免先组合哪一组意外造成推理死路。

### 2.3 合并的可靠性

- 同一次合并的输入移除、结果创建、任务变化和提示一起保存。
- 无效组合保留输入，主角说明证据缺口。
- 交换输入顺序得到同样的结果。重复点击、刷新和返回页面均不能复制卡片。
- 现场的同一发现只登记一次，合并后回到现场查看会打开已有结果卡中的相应记录。
- 同一事实的信任奖励、情报售价和使用次数随证据继承，合并后继续保留结算记录。
- 读详情与思考不推进游戏时钟，实地调查和交涉按行动耗时。

以下 ID 用于设计引用，沿用名称相同的现有线索内容。落地时建立明确映射，现有角色已经取得的线索保留来源和奖励记录。

### 3.2 码头与引荐

| ID | 线索 | 实际取得场景 |
|---|---|---|
| D01 | 船长警惕陌生的本地人 | 第一次接近登船区，被艾尔兰询问身份并拒绝 |
| D02 | 船员愿意替人递话 | 被拒后，一名船员前来交班，暗示替人传话会耽误自己的工夫 |
| D03 | 船员已经为我引荐 | 根据推测付钱请船员递话，看到他带自己走向船长 |
| D04 | 船长要求证明与污染筛查 | 正式接触后，听船长说明乘客安全与准入要求 |
| D05 | 临时安置会让船方承担额外费用 | 引荐完成后，听见船员谈隔离舱、看守与延误成本 |
| D06 | 船长报出的高额条件 | 有依据地试探金钱交涉，听到具体金额与附加条件 |
| D07 | 格尔曼的姓名、特征与行踪 | 船长说明可以找谁提供可核实的担保，亲口给出姓名与去向 |
| D08 | 最后交涉与登船的时间安排 | 船长告知最后申请时段和离港前手续用时 |

D03 对应已经发生的引荐，世界状态也记录这件事。买到或听说别人曾被引荐，不会产生“自己已被引荐”的事实。

## 4. 组合配方

### 4.1 给格尔曼的情报

| 配方 ID | 两张输入卡 | 结果卡 | 可解锁的表达 |
|---|---|---|---|
| R01 | A03 教堂收据 + A04 运输记忆 | 教堂运输委托 | “我可能就是运那只箱子的人。” |
| R02 | R01 教堂运输委托 + A05 侧门痕迹 | 教堂运输路线的疑点 | “收据、我的记忆和侧门痕迹指向同一趟运输。” |
| R03 | A06 漂浮灯火 + A12 堂娜的目击 | 可以相互核对的无头目击 | “我看到的异常，与这个女孩看到的可能是同一个。” |
| R04 | A13 电报局答话 + A14 染血纸条 | 电报局正在维持异常的工作 | “门内还有人工作，可他们的回答和门下的血都不正常。” |
| R05 | A10 无法说出姓名 + A11 机械回答 | 门外来者可能在模仿邻居 | “那个人反复叫自己邻居，却答不出最简单的问题。” |
| R06 | A01 记忆空白 + A02 未寄出的信 | 我曾记得一件需要隐瞒的事 | “我发现自己写过一封信，但现在完全想不起为什么。” |

R02 提到“地下储藏室”的部分只能来自已经获得的运输记忆或后续核问。取得储藏室事实后，卡片可以更新为“教堂地下储藏室的运输疑点”，并保留该事实的取得来源。配方遵循实际内容逐步补齐结论。

R03 出示前可以向堂娜核对时间地点。R04 只支持电报局存在异常，人员死亡和失踪需要次日的独立发现。R05 为合理怀疑，人物可以要求更多证据。

|---|---|---|---|
| R07 | A06 漂浮灯火 + A07 灯光照明 | 用灯试探夜路 | 提出试探方案，现场继续检查灯是否点燃 |
| R08 | R07 用灯试探 + A08 身影暂时停下 | 灯火带来的短暂掩护 | 记录本次路段的有限效果 |
| R09 | R08 短暂掩护 + A09 迫近现象 | 灯火保护有时间上限 | 合并后说明本次路段的掩护已经失效，记录观察到的持续时长 |
| R10 | A15 第一夜人影 + A16 次日血迹 | 电报员在一夜间消失 | 引导追查血迹与旧墙，保留未知原因 |
| R11 | R10 电报员消失 + A17 墙下图案 | 电报局旧墙值得继续调查 | 开放关于图案的进一步观察与询问 |
| R12 | A18 灰鸥号航线 + A19 潮汐窗口 | 外海接近计划 | 计划包含实际时刻和下海位置 |
| R13 | R12 外海接近计划 + A20 求救信号 | 向灰鸥号求救的准备方案 | 海上行动继续检查能力、实际携带物、体力与窗口 |

推理能让玩家理解准备事项。玩家也可以先做出有效行动，再将结果整理到线索簿。实际危险、物品效果和能力条件依据世界状态结算。

十分钟是本幕的机制上限。R09 的角色记录依据实际遭遇表述为“灯火仍亮着，掩护却已失效”，并列出前后观察时间；安全提示可以明确告知该路段最长十分钟，角色不会由一次遭遇断言所有异常都遵循同一规则。

|---|---|---|---|
| R14 | D01 船长拒绝陌生人 + D02 船员愿意递话 | 可以花钱请船员引荐 | 对该船员提出一笔辛苦钱 |

原始线索也可以直接解锁较窄的话题。例如 A23 可以询问旧物价格，A24 可以询问消息怎么报价。R17 把两类服务整理到同一张卡，方便后续查阅。

## 5. 格尔曼的具体对话条件

### 5.1 先知道要找谁

D07 由船长亲口提供。建议对白如下。

> “有一位旅客正在查这座镇子的事。格尔曼·斯帕罗，黑礼服，戴礼帽。”
>
> “他在青柠檬餐厅办事。你要是确实知道什么，就带着能核对的东西去找他。”

这段属于游戏改编交互。线索详情记录船长告知的预期行踪、取得时间和可能变化。超过格尔曼的活动窗口后，地点记录标记为已过时。

取得 D07 后，任务簿出现“寻找格尔曼·斯帕罗”。到餐厅并匹配人物外观时，才出现对应的辨认与接触话题。此前餐厅中的人物按主角所知显示为陌生旅客。

### 5.2 情报与信任奖励

下表的信任数值沿用第一幕既有奖励分组，成功核验后记分。

| 话题 | 必要线索 | 附加条件 | 建议结果 |
|---|---|---|---|
| 说明刚醒来与记忆空白 | A01，或包含 A01 的结果卡 | 已取得 D07，并能接触本人 | 首次坦诚 +10 |
| 出示教堂收据 | A03，或 R01、R02 | 已取得 D07，收据拓录可用 | 核实后 +25，教堂证据组只计一次 |
| 解释运输路线 | R01 或 R02 | 当前卡片已包含所说的路线事实 | 追问更深入，沿用教堂证据组 |
| 提供独立目击或电报异常 | R03、R04，或足以核验的原始目击记录 | 说得出亲历与证词的来源 | 核实后 +20，异常证据组只计一次 |
| 说明对自身污染的担心 | R06 | 已读过信且确有记忆空白 | 坦白风险 +15 |
| 提到援救 | A25，或其后续结果卡 | 援救真实完成，可被核对 | +35，只计一次 |
| 请求担保 | D04、D07，或继承它们的结果卡 | 信任至少 60、核验证据、筛查及船期条件满足 | 格尔曼给出判断，船长执行准入决定 |

两种可行的信任组合为“首次坦诚 10 + 教堂证据 25 + 异常证据 20 + 风险坦白 15 = 70”和“援救 35 + 教堂证据 25 = 60”。每组背后的事实都必须实际取得。

玩家有原始线索时，可以先提供不完整情报。对方针对缺口追问，形成下一步调查方向。界面不能在尚未发现收据时预先列出“出示收据”。

## 6. 码头的两级交涉

### 6.1 首次被拒

玩家点击地图前往码头，接近登船处，艾尔兰主动问身份并表达警惕。

> “班西人？今晚的情况你也看见了。我不能让一个来历不明的人上船。”

取得 D01。此时可观察船边、退到岸边或离开，特殊付费话题继续等待相关依据。

### 6.2 从船员的行为中找到办法

一名值班船员前来交班，看到玩家被拦住，低声说出暗示。

> “船长忙着清点人。谁替你递话，谁就得多跑一趟。”
>
> 他说完没有立即走开，手指在自己的旧钱袋上敲了敲。

取得 D02。组合 D01 与 D02 得到 R14。玩家现在可以选择“拿出一点钱，请他替自己递话”，预览金额和耗时后确认。

付费成功后，船员实际领玩家接近船长，取得 D03。该阶段只建立正式交谈机会，下一阶段按照船长的条件继续。

### 6.3 船长透露格尔曼

船长说明准入要求，得到 D04；指出格尔曼正在调查异常，得到 D07；交代最后交涉与离港安排，得到 D08。

玩家因此可以离开码头去调查与寻人，也可以继续观察船方处境，寻找金钱交涉的依据。

第一夜初次接触建议放在 22:17–00:00 的早期时段，取得行踪后有机会赶上格尔曼 00:20–01:10 的餐厅活动。初次接触只涉及信息与意向，最后登船申请沿用 05:00–05:30 的交涉窗口与 06:00 离港规则。

上述初次接触时段为新安排，实施时需要把房内调查、去码头、引荐、往返餐厅的用时一起试跑。

### 6.4 高额交涉的发现

已被引荐后，玩家可以听见船员与船长谈临时安置的额外开销，取得 D05。组合 D04 与 D05 得到 R15。

此时才出现“提出额外酬金，请他破例接纳自己”的试探话题。船长报出很高的金额并坚持污染检查，取得 D06。

这条拟加入的高价分支涉及艾尔兰接受额外酬金的游戏改编行为。对白需体现他对船员和乘客安全的顾虑，并与本项目原著人物边界一起评审。

### 6.5 最后申请

| 路径 | 前置证据 | 额外条件 |
|---|---|---|
| 格尔曼担保 | D03、D04、D07、D08 及对应担保记录 | 格尔曼的有效判断、筛查通过、申请和登船时刻合法 |
| 高额酬金 | D03、D04、D06、D08 | 足额金钱、筛查通过、申请和登船时刻合法 |

高额酬金分支是此次新增的稀缺解法，成功条件同时包含资源与情境。角色处于失控终局、明显污染、许可因欺骗被撤销或客船已离港时，金钱交涉按相应场景结束。

最终批准前显示报价、交涉耗时、登船所需时间与剩余窗口。确认时一起校验资金、船期和许可。失败的未成交请求不扣钱，已经完成的船员引荐服务保持已支付状态。

## 7. 金钱与交易的第一轮平衡

### 7.1 金额草案

统一以整数金钱单位记账，具体货币名称后续随项目表现确定。以下为可试算的第一版价格。

| 项目 | 金额 | 作用 |
|---|---:|---|
| 玩家初始金钱 | 24 | 可支付基础服务，需要为高价路线筹资 |
| 船员引荐 | 8 | 取得与船长正式交谈的机会 |
| 收费借火一次 | 2 | 在实际火源处由值夜人帮忙点灯 |
| 船长高额酬金 | 120 | 开启昂贵登船分支，另需筛查与合法船期 |

高额路线连同一次引荐、一次收费借火共需 130。初始金钱只覆盖其中 24，需要额外筹集 106。

### 7.2 家中可出售的物品

建议由港边一位游戏原创收货人经营旧物收购与本地消息交易。玩家先观察他的交易，取得 A23、A24，再出现对应的出售话题。

| 物品 | 建议售价 | 出售后的直接变化 |
|---|---:|---|
| 黄铜手提灯 | 20 | 从可携物中移除，原来的照明与求救能力随持有状态变化 |
| 生锈水果刀 | 6 | 从可携物中移除 |
| 备用旧外套 | 12 | 作为新增可售家当取走并交付 |
| 备用毯子 | 10 | 作为新增可售家当取走并交付 |
| 铜杯 | 4 | 作为新增可售家当取走并交付 |
| 家中空木箱 | 8 | 检查与清空后可以搬走出售，占两格携带位 |
| 合计 | 60 | 需要在路程、两格背包与保留工具之间取舍 |

旧外套、毯子、铜杯和空箱为建议补入的本地家当，具体地图热点需要随住宅布局制作。床下储物箱如承载剧情线索，需先明确其内容并允许玩家决定何时清空。

其他实际取得的可交易物品也登记收购价。受委托保管的怀表等物品，出售前由场景明确记录其归属与本幕任务后果，长期人物命运另行创作。

### 7.3 线索如何卖钱

本稿建议把卖线索设计为向买家出售情报副本。交易后，玩家的线索卡保留并标记已出售，知识继续用于推理和交谈。这个细节是本稿补充的默认设计。

线索簿中的原始线索和组合结果均可进入报价。复合结果按其包含的、尚未结算的事实估价。收购人得到同一事实后只支付一次，后续换标题、组合或分拆展示的内容继续沿用原付款记录。

| 情报 | 建议首次售价 |
|---|---:|
| 未寄出的信所记录的内容 | 15 |
| 教堂运输收据的记录 | 25 |
| 床下储物箱的擦痕 | 5 |
| 窗外亲眼观察到的异常 | 10 |
| 隔门交谈记录 | 10 |
| 自己恢复的运输记忆 | 10 |
| 其他独立调查事实 | 按事实登记，首轮基准 5 |

“教堂收据 + 运输记忆”合成后可报价 35。若收据已经售出，只对尚未出售的运输记忆报价 10。新的独立核验发现可以单独计价，单纯重新整理不产生新情报价值。

出售纸质原件时，物理所有权单独记录。已经拓录的内容继续保存在结果卡内，后续话题如果需要原件，则额外检查是否仍持有原件。

### 7.4 筹资试算

一种高价路线的筹资样例为初始 24、卖家当 60，以及出售上述前五类情报 65，总计 149。支付引荐、借火和船长酬金共 130 后，剩余 19。

如果保留手提灯，这组资金减少 20，合计 129。玩家需要再取得并出售一条独立消息，或改变其他筹资安排。

这说明当前价格在金额上允许筹齐费用，但会占用家当、调查时间与信息披露。具体价格需要结合真实可达时段试跑，本稿试算尚未证明该完整筹资过程能在船期前完成。

### 7.5 交易结算

- 钱包不占实体背包格。
- 出售前显示买家、物品或情报、金额、耗时和实际交付内容。
- 交易确认时再次校验物品持有、事实付款记录、余额与人物可用时段。
- 一次写入金钱变化、物品转移、已售事实与新线索。
- 连点、刷新、同一事实再次发现和多张卡片中的重复引用均保持唯一结算。
- 买回物品时，保留真实所有权与位置。买卖价需避免无限循环获利。

## 8. 手提灯重燃与收费借火

手提灯分别记录“是否持有”“是否点燃”“各危险路段的警觉与保护截止点”。熄灭后可以在实际可用的火光旁重新点燃。

| 情况 | 可用操作 | 金钱 |
|---|---|---:|
| 家中炉膛仍有可安全接近的火 | 调查取得 A21 后，用余火点灯 | 0 |
| 餐厅或码头的火源由值夜人看管 | 取得 A21、A22，或组合 R16 后请求借火 | 2 |
| 当前地点缺少可接近火源 | 依据已经发现的火源位置前往借火 | 按实际地点结算 |
| 灯仍亮着 | 查看灯的状态 | 0 |

收费借火的场景可以写为值夜人护住灯罩，先问“是要借个火？我得替你挡着风”，随后报出少量辛苦钱。玩家听到并登记 A22 后，才出现具体付费话题。

建议成功借火用时两游戏分钟，先在火源处结算，随后继续移动。灯的危险路段保护在该路段首次有效使用时登记，同一区域的已用保护继续保存。

重新点燃恢复照明状态。十分钟路段保护的原截止点保持有效，已经过期时再次借火也无法获得同一遭遇的新保护。

## 9. 获得线索与属性变化提示

### 9.1 获得线索

行动旁白之后，显示高辨识度的轻提示，并在笔记入口出现短暂标记。

> 获得线索《教堂运输收据》

轻提示建议停留约四秒，点击直接打开详情，世界时钟暂停。已取得过的事实使用“线索记录已更新”，实际组合结果使用“线索已组合”，结果卡短暂高亮。

组合成功的提示应明确说明两张原卡已经归入结果详情，便于玩家理解列表数量减少。

### 9.2 数值提示的颜色与文字

| 变化 | 提示示例 | 建议颜色 |
|---|---|---|
| 理智下降 | 理智 −30 | 明亮红色，同时显示向下标记 |
| 失控增加 | 失控度 +25% | 红橙色，同时显示危险标记 |
| 获得线索 | 获得线索《门外来者的疑点》 | 暖金色或清晰的浅色 |
| 获得金钱 | 金钱 +15 | 金色 |
| 支付金钱 | 支付 −2 | 琥珀色 |
| 体力下降 | 体力 −2 | 与理智、失控可辨认的淡蓝色 |

数字始终使用本次实际结算差值。例如理智从 20 降至 0，提示实际损失 20。失控度的显示单位与状态栏一致，从 50% 升到 75% 时可显示“失控度 +25%，当前 75%”。

“理智 −30”为提示样式示例，具体扣值继续来自对应事件设计。每种变化同时提供文字、正负号与必要图标，保证颜色辨认困难时仍能理解。

同一事件的线索、属性和金钱提示按固定顺序逐条出现。发生死亡或失控终局时优先呈现终局反馈，行动结算日志保留之前的实际变化。

## 10. 实现时的数据约定

本节描述职责与证据判定方式，具体代码沿用既有事件解释器逐步扩展。

| 记录 | 保存内容 |
|---|---|
| 活跃线索卡 | 卡片 ID、类型、事实集合、推测、核验状态、原始记录详情 |
| 发现记录 | 事实 ID、实际取得事件、来源、地点、时间 |
| 话题依据 | 该话题要求的事实或推理，以及玩家能说出的内容 |
| 合并记录 | 输入卡、配方、输出卡和已经发生的副作用 |
| 情报交付记录 | 对方、已出示事实与已领取的信任奖励组 |
| 交易记录 | 买家、实际出售的事实或物品、金额、耗时 |
| 借火记录 | 当前灯状态、实际火源、路段保护与警觉 |

条件对话从活跃卡片解析已承载的证据。发现记录用于追溯与防重复奖励，已经通过组合进入结果卡的事实由结果卡继续提供。

新增一条条件话题时，需要同时提供“事实如何取得”“组合后如何继承”“人物何时能接触”“交涉何时结算”四项。已有的普通按钮要据此逐一改写为有情境来源的动作。

## 11. 下一版验收

- [ ] 尚未查到收据时，格尔曼处没有对应情报话题。
- [ ] 原始收据可打开较窄话题，组合结果可打开更完整的表达。
- [ ] 未从船长处取得 D07 时，玩家没有直接辨认与寻找格尔曼的专属选项。
- [ ] 两张卡组合后从列表消失，只保留结果卡，详情中能追溯原事实。
- [ ] 收据合并后仍可在交谈中出示相应记录，重复合并与刷新不复制奖励。
- [ ] 多组推理在不同顺序下可以继续，已经归入同一卡片的事实可从详情继续推演。
- [ ] 每次取得新线索有明显提示，点击提示与卡片都能打开详情。
- [ ] 理智减少与失控增加使用明确的颜色、数字和文字，显示实际变化值。
- [ ] 发现船员的暗示后才可组合出付费引荐方案，付款后确有引荐事件。
- [ ] 船长给出证据要求与格尔曼行踪，玩家可以据此选择继续调查。
- [ ] 船长高价交涉须先得到费用线索，足额金钱、筛查与船期共同决定成交。
- [ ] 廉价借火须有实际火源，重新点燃保持同一路段原有警觉和保护期限。
- [ ] 家当出售改变实际物品所有权，情报出售按事实唯一付款。
- [ ] 高价路线完成时间可以通过可复查的实际流程证明，价格根据试跑结果调整。

## 12. 本稿新增的设计判断

1. 情报出售默认保留玩家知识与卡片，并标记已经出售的事实。组合消耗卡片按用户要求执行。
2. 初始金钱 24、引荐 8、借火 2、船长酬金 120，以及家当和情报价格均为平衡草案。
3. 增加港边收货人与可售家当，作为第一幕的交易入口和筹资来源。
4. 船长的初次信息接触与清晨最后登船申请分开安排，使寻找格尔曼在时间上具备可能。
5. 高额酬金为新增的游戏改编登船分支，具体对白与艾尔兰接受金钱的尺度需要与人物设定一起评审。

本稿完成后，后续实现应同步更新对应剧本、数据、机制与验收。上述数值与新增场景当前处于设计阶段。
