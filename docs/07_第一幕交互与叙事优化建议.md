# 《血雾班西》第一幕交互与叙事优化建议

版本 v1.1 · 2026-11-18 · 产品设计稿

本文将项目负责人最新要求整理为下一轮改版依据，覆盖苏醒引导、地点探索、人物交谈、线索组合、旁白呈现、转场和关键事件展示。新增的内心独白与线索配方均为建议稿，具体实现前应与原剧本逐段衔接。本文交付为设计文档。

本版补充了条件对话的线索前置、组合消耗原卡片、获得线索提示、属性变化提示、重新点灯与交易。完整配方、码头交涉流程及试算价格见 [线索组合与情报交易设计](08_线索组合与情报交易设计.md)。

## 1. 改版目标与玩家体验

保留文字、插画和点击操作，让玩家主动调查地点与人物，利用证据形成判断，并选择行动方式。第一幕围绕“查清失忆的原因”和“活着离开班西港”同时推进。前者承接长期悬念，后者提供本幕可以达成的目标。

玩家的一次完整调查应形成下面的过程。

```mermaid
flowchart LR
    A[进入地点] --> B[观察环境与人物]
    B --> C[点击调查对象]
    C --> D[记录事实]
    D --> E[组合线索形成推测]
    E --> F[选择行动或核验证据]
    F --> G[世界与人物作出回应]
    G --> A
```

改版后的玩家应当能够回答三个问题。

1. 我现在为什么要调查这里。
2. 我发现了什么，它与之前的发现有什么关系。
3. 我接下来可以尝试什么，会付出什么代价。

### 1.1 已明确的改版要求

| 需求 | 下一版的具体表现 |
|---|---|
| 苏醒动画与旁白 | 从黑暗、模糊视野和头痛中醒来，随后获得主任务 |
| 场景引导 | 通过主角自语、声音、光线和物件状态提醒可调查方向 |
| 线索组合 | 玩家从线索簿选择证据，形成有来源、可验证的推测 |
| 无边框旁白 | 场景上叠加文字，去掉矩形弹窗边框和下一步按钮 |
| 五秒自动翻页 | 每段完整呈现后停留五秒，点击旁白覆盖区域即可前进 |
| 房内地图 | 点击卧室、客厅、厨房等区域，到达后调查具体物件 |
| 地区地图 | 点击餐厅、电报局、码头等目的地移动 |
| 步行转场 | 角色行走剪影或脚步演出连接两个地点 |
| 关键事件展示 | 晋升等事件使用插画演出与清晰的结果卡片 |
| 更自由的剧情推进 | 地点、话题和任务依据世界状态开放，支持不同调查顺序 |

### 1.2 需要衔接的既有设定

| 新需求中的示例 | 本稿建议采用的衔接方式 |
|---|---|
| “我是谁，我在哪里” | 先短暂迷茫，再通过房间、名字与港口记忆恢复定位。失忆集中在当天经历 |
| “现实世界根本不存在” | 使用“我在班西生活了这么久，从没见过这种东西”等当地人的表达 |
| “夜里点灯就不会被攻击” | 先形成短时掩护的推测，再用遭遇结果核验。保护最长十分钟，路段警觉持续记录 |
| 厨房里取刀 | 将水果刀的交互位置移至厨房，沿用道具 ID 与用途，同步调整场景描述和图中物件 |
| 点击地图后行走 | 使用地点连接和短转场，地图显示角色所在位置 |
| 调查失忆原因 | 作为持续主任务，本幕只取得阶段证据。失忆真正原因、木箱内容和信件收件人仍待后续创作决定 |

第一夜电报局强闯死亡、白玛瑙号离港关闭路线、异常吸收猎人特性、两格实体背包、死亡封存等规则，均应进入新版的条件判定与验收。剧情中的人物回应应遵循角色设定，格尔曼依据证据与行动判断玩家，艾尔兰决定登船许可。

## 2. 苏醒与开场引导

### 2.1 苏醒演出

建议用现有卧室插画、遮罩、模糊变化和轻微镜头位移制作第一人称苏醒。建议新增效果均支持减少动态效果设置，演出时长属于现实播放时间。

| 阶段 | 建议演出 | 文字或声音 |
|---|---|---|
| 黑暗 | 约一秒黑幕，渐入海浪和呼吸 | 让玩家先听见环境 |
| 睁眼 | 约两秒的视野开合，天花板从模糊转清 | “头……好痛。” |
| 起身 | 镜头轻微抬起后稳定，避免持续晃动 | “我睡了多久？” |
| 认出房间 | 展示床沿、桌面与窗帘透入的红光 | 接入原剧本关于名字、班西港和当天记忆空白的段落 |
| 接受目标 | 画面稳定，出现简短任务提示 | “我记得自己，也记得这间屋子。可今天发生过什么……一点都想不起来。” |
| 自主调查 | 任务提示收起至任务簿，房内地图可交互 | 由玩家选择先去窗边、桌前、厨房或门口 |

苏醒段落完成或被跳过时，主任务只登记一次。首次进入调查界面仍为 1 月 9 日 22:17。重复查看开场、暂停和刷新均应保留已登记的任务。

### 2.2 主任务与阶段目标

**主任务《调查你失忆的原因》**

任务描述建议如下。

> 你记得自己的名字，记得码头的工作，却想不起今天发生了什么。先看看家里，找出这段空白留下的痕迹。

任务簿记录调查方向与玩家已得出的判断。第一阶段同时提供“调查住所”“尝试回忆白天的经历”两个方向，允许自由选择顺序。

| 玩家取得的进展 | 任务记录 |
|---|---|
| 阅读未寄出的信 | 自己曾经记得某件危险的事，却没有留下明确解释 |
| 查看教堂运输收据 | 当天可能接过运送木箱的委托 |
| 结合信件、收据或记忆片段 | 新增调查方向“核实教堂运输委托” |
| 听到汽笛或得知白玛瑙号 | 新增本幕主任务《离开班西港》 |
| 完成 A 或 B 逃生 | 逃生任务完成，失忆任务保留已知证据与未解问题 |
| 死亡或毁灭 | 封存本次角色和任务进度，成就图鉴按既有规则保留 |

避免用“调查完房间全部对象”作为强制通行条件。玩家可以带着疑问离家，也可以承担调查带来的时间成本。

### 2.3 环境变化后的主角反应

每个关键发现包含环境事实、身体反应、内心判断三层。内心判断只能使用该角色已经掌握的信息。

**拉开窗帘的建议演出**

窗帘打开一角，红光压进房间。先看见悬浮的灯火，再短暂辨认出头颅轮廓或下方缺失的身体。画面轻微停顿，呼吸一滞，随后显示内心独白。

> 我一下攥紧了窗帘。那盏灯下面……为什么没有人？
>
> 刚才晃过去的，像是一张脸。
>
> 我在班西生活了这么久，从没见过这种东西。先把窗帘拉上。

首次发现写入“夜雾中的漂浮灯火”。玩家进一步细看时，才按观察内容补充“头颅轮廓”或“无头身影”。观察细节可以消耗时间并带来剧本规定的精神压力，重复回看已记录文本不重复扣除。

**听见邻居机械应答后的建议独白**

> 他一直说自己是邻居，却连名字都答不上来。
>
> 每个字之间都停了那么久……门外真的是我认识的人吗？

记录“机械的邻居”，并把门缝、门闩、静听等交互保留在场景中。玩家靠近门闩时应先获得可观察的危险征兆，再自主决定是否开门。

### 2.4 引导出现的时机

- 必要任务首次出现时，播放一次简短提示，并记入任务簿。
- 有明确声音、光线或人物动作时，由这些变化引出调查对象。
- 玩家停留时，可以轻微强调已经可见的物件轮廓。阅读和思考期间暂停世界时钟。
- 回访地点只呈现变化与新发现，完整正文可随时回看。
- 减少动态效果时，用静态画面与文本承接同样的信息。

## 3. 房内地图与物件调查

### 3.1 房内结构

建议采用一张可点击的住宅平面插画，连接卧室、客厅、厨房和门厅。点击区域后进入该区域的插画或局部视图，保留可返回住宅地图的入口。

| 区域 | 可见对象 | 建议交互 |
|---|---|---|
| 卧室 | 床、窗帘、床下储物箱 | 起身、拉开窗帘、细看窗外、查看箱子 |
| 客厅 | 桌面、黄铜手提灯、盘下的信、教堂收据 | 观察、点灯、拾取、阅读、拓录 |
| 厨房 | 刀架、水果刀、晚餐碗碟 | 检查、拾取刀、闻气味 |
| 门厅 | 外门、门缝、门闩 | 静听、隔门询问、观察门缝、开门 |

这些区域为本次建议新增的空间布局。素材制作时需统一门窗和通道位置，并把原卧室画面中的刀、晚餐等物件位置与新布局对齐。

### 3.2 一次物件交互

以厨房的水果刀为例。

1. 玩家点击住宅地图中的厨房。
2. 播放短步行转场，进入厨房视图。
3. 玩家点击刀架上的刀，出现近景或物件名称。
4. 显示简短描述，并提供与该对象有关的“拿起”“放回”操作。
5. 拾取成功后，背包出现道具，场景显示取走后的刀架。

全场景保留地图、背包、线索簿和任务簿入口。操作面板在选中物件后出现，提供该对象当前可用的少量动作。

### 3.3 可发现性与背包规则

- 桌面、窗帘、刀架等关键对象在画面上可辨认，悬停、键盘聚焦或点按时显示名称。
- 已调查对象保留简洁状态，物件发生变化时重新提示。
- 两格背包装满时，玩家可在安全地点选择放下一件，再取走目标物。
- 放下的实体道具记录实际地点，回到该地点后可以再次取得，受世界事件影响的物件另有明确记录。
- 信和收据阅读后写入线索簿，收据沿用已拓录可出示的约定。
- 点击空白处可以取消物件选择。危险进行中使用相应的行动规则。

新增区域后的路程与调查耗时需要统一核算。建议房内短距离移动先按零游戏分钟处理，调查、取物和跨地区移动计时，避免新增转场把既有敲门窗口变成意外死限。

## 4. 地区地图与步行转场

地区地图展示已知的住所、旧街、餐厅、电报局、码头、教堂外围和旧灯塔。图上明确标出当前位置与可用连接。玩家点击目的地后，可查看预计路程，再确认出发。

不同日期影响地点状态。地图可以显示“门内仍有灯”“白玛瑙号已离港”“旧灯塔道路开放”等角色能够感知的信息。尚未发现的秘密地点通过调查逐步揭示。

### 4.1 步行演出规格

建议使用两至三帧角色剪影步行循环，配合少量背景平移和脚步声，单次转场约 0.8–1.5 秒。长路程同样采用短演出，预计耗时由文字说明。

点击步行画面可跳过剩余动画。跳过只缩短现实播放时间，世界内路程费用照常结算。

移动流程建议采用如下顺序。

| 阶段 | 输入与输出 |
|---|---|
| 确认出发 | 校验当前位置、连接、行动条件和预计完成时间 |
| 计算结果 | 顺序处理路途中跨过的世界事件，得到到达、遭遇或被打断的结果 |
| 提交状态 | 一次写入耗时、位置、事件结果和待播放演出 |
| 展示转场 | 播放与已提交结果对应的步行或遇险画面 |
| 展示目的地 | 呈现最新地点状态及新旁白，恢复可操作对象 |

路途中发生敲门、离港或毁灭等事件时，按事件实际作用范围处理。已离家的角色继续留在其实际地点，错过客船后码头画面随之改变。

同次出发的连续点击只结算一次。刷新或关闭页面后，继续已提交的结果，避免重复扣时、重复取物或回到移动前的位置。

## 5. 线索簿与组合推理

### 5.1 事实、推测与核验

每条线索支持点击查看详情，保留来源、取得时间、观察正文和相关人物。记录线索后，玩家可以选择两条进行组合。组合成功后两张原卡片从线索簿列表中移除，只保留一张结果卡。结果卡继续携带原证据的内容和用途，可参与后续组合。

| 条目状态 | 含义 | 使用方式 |
|---|---|---|
| 观察记录 | 玩家见到、听到或读到的内容 | 作为调查依据，人物证词需注明说话者 |
| 待核验推测 | 多条记录支持的一种解释 | 开放验证方向、物品使用方案或新话题 |
| 已核验结论 | 有行动结果或独立证据支持 | 用于交涉、路线规划和任务进度 |
| 需要修正 | 出现冲突证据，原判断适用范围需要调整 | 保留原推理与修正原因 |

“记录过某人的说法”与“证实了那件事”分别保存。玩家的组合行为改变角色掌握的知识，实际物品、人物位置和危险仍由世界状态决定。

### 5.2 组合操作

1. 打开线索簿，点选线索卡片。
2. 点击“尝试关联”，展示所选记录的来源。
3. 有合理配方时，出现一段主角推理并生成新条目。
4. 证据不足时，主角说明当前缺口，例如“我知道它在夜里出现，但这还解释不了它为什么停下来”。
5. 若形成可操作判断，显示“可以在街口试着用灯观察”之类的调查方向，玩家自行决定是否执行。

成功关联会消耗两张原卡片，并生成一张结果卡。原始事实、来源与已解锁话题继承到结果卡详情中。同一配方只结算一次，选择顺序不影响结果。失败组合保留输入卡片。阅读、整理和组合默认不推进世界时钟，前往现场验证按行动计时。单纯的无效组合不扣理智。

组合配方由作者编写并保留稳定 ID。界面可以让玩家试着关联任意已有条目，结果由明确证据和规则解释。

### 5.3 灯光推理的完整示例

用户提出的“夜里的人头灯笼”和“灯光驱散黑暗”作为第一组教学线索。

| 步骤 | 玩家得到的信息 | 对应玩法 |
|---|---|---|
| 窗边观察 | 漂浮的灯火在夜雾中移动，灯下看不见正常行人 | 记录夜间目击事实 |
| 点燃手提灯 | 火焰照亮近处，物体的轮廓重新清晰 | 记录灯光对周围环境的影响 |
| 组合两条记录 | “如果那东西借黑暗靠近，带着灯或许能让我多看清一点，也争取一点时间。” | 生成待核验推测《用灯试探夜路》 |
| 第一次街口试探 | 点灯后，该次遭遇中的身影暂时没有扑近 | 记录行为证据，将推测升级为《灯火带来的短暂掩护》 |
| 时间接近上限 | 灯还亮着，雾中的身影却逐渐靠近 | 写明保护最长十分钟，同一路段不能通过重燃重置 |

一次夜间目击只能支持“曾在夜里出现”。“它只在夜里出现”需要更多证据。灯光照亮房间支持一个可尝试的方案，街口遭遇结果支持该方案的有限效果。

获得推理之前，玩家也能直接点灯、静听、等待或绕行。直接行动发现的结果可以反过来补全线索，避免把组合教学变成离家的必经手续。手提灯对第一夜电报局强闯的判定仍无保护作用。

熄灭的手提灯可以在有可用火源的地点重新点燃。借火对象、服务价格和收费交涉通过场景调查取得线索后开放。同一路段的警觉与十分钟保护截止点持续保存。

### 5.4 第一幕建议组合

下表中的结果为新增推理文案建议。事实内容来自现有剧本，新增实地验证须在后续实现时补齐演出。

| 输入记录 | 形成的判断 | 状态及后续用途 |
|---|---|---|
| 夜雾中的漂浮灯火 + 点灯后的照明变化 | 可以用手提灯试探夜路 | 待核验，供玩家选择用灯行动 |
| 手提灯试探成功 + 掩护期结束时的迫近 | 灯火只能争取有限时间 | 已核验，记录路段和适用期限 |
| 邻居无法说出姓名 + 机械重复的邻居称呼 | 门外来者可能在模仿熟人 | 待核验，支撑警惕与进一步观察 |
| 亲眼看到的异常身影 + 堂娜的独立目击 | 需要交叉核对的异常目击 | 待核验，向堂娜追问时间地点；吻合后可向格尔曼出示 |
| 未寄出的信 + 白天的记忆空白 | 自己曾试图隐瞒或保存某段记忆 | 待核验，更新失忆主任务的调查方向 |
| 教堂收据 + 暴雨与木箱的记忆片段 | 自己可能参与过教堂运输 | 待核验，开放核对委托事实的话题 |
| 教堂收据 + 教堂侧门箱车痕迹 | 运输路线与侧门痕迹可能有关 | 待核验，现场痕迹足以核对后才作为已验证情报 |
| 第一夜两个静止的人影 + 第二天两滩血迹 | 电报局人员在一夜之间发生异常变化 | 观察支持的调查结论，引导查看血迹指向 |
| 血迹指向旧墙 + 剥落的墙皮 | 墙后隐藏的信息值得调查 | 待核验，开放仔细查看旧墙的方向 |
| 灰鸥号航运记录 + 灯塔观潮记录 | 可规划外海接近地点与时间 | 可核验的路线计划，下海仍检查猎人能力、体力、信号与时间 |

收到矛盾证据时，修正推测的适用范围并保留来龙去脉。错误推测可以带来调查成本，具体危险应由玩家能察觉的场景征兆提示。

### 5.5 知识与奖励的边界

- 组合获得新话题，不直接使 NPC 相信玩家。
- 同一事实换一种组合方式出示时，仍只计算一次对应的信任收益。
- 推测的未核验状态在出示时可辨认。人物可要求物证、目击细节或实际行动。
- 形成海上路线计划不替代成为猎人，也不替代携带求救信号。
- 未发现的非凡术语按知识进度逐步开放，人物保持其已有知识与动机。

## 6. 更自由的任务与人物交谈

地点中先选择人物，再看到当前可谈的话题。第一次寒暄、讨论某件证据、做出道德决定，分别记录是否发生及结果。

所有条件对话都需要前置线索。前置可以是原始卡片，也可以是包含对应事实的组合结果卡。未获得依据时，界面隐藏该话题；取得依据后，再校验人物日程、地点、关系、金钱和已完成事件。通用问候、告别与取消属于基础操作。

对话中互相冲突的答复保留明确后果。独立话题按各自条件开放，玩家获得新线索后可以回访，在人物仍可接触时继续交流。

### 6.1 格尔曼担保的两个推进示例

| 路径 | 调查顺序 | NPC 判断依据 |
|---|---|---|
| 情报核验 | 调查收据 → 在码头获船长告知格尔曼行踪 → 取得目击证词 → 找到格尔曼并出示证据 | 物证、可核实情报与坦诚 |
| 援救与证据 | 从船长处得知格尔曼行踪 → 获得危险征兆 → 阻止旅客遇险 → 与格尔曼核验运输证据 | 实际援救与可验证事实 |

路线均受人物日程、信任、证据、筛查和船期制约。玩家先来过或先完成其中某件事，对方对白应体现这段经历。

### 6.2 关系记录的建议调整

现有实现中，格尔曼信任首次低于零便永久关闭私人交谈。建议在本轮设计中重新审视这一规则，并分别记录“对说法存疑”“拒绝谈某个话题”“拒绝担保”“因严重行为断绝接触”等具体后果。

这些状态可以支持更符合人物性格的回应。新证据出现后，人物是否愿意重新核验，由明确事件决定。严重隐瞒污染、危及乘客等行为仍应产生相应后果。

该部分涉及当前人物行为调整，实施前需在对应剧情中写出完整的进入条件、回应和终止状态。此次产品稿建议先完成调查与线索组合，再逐段调整人物反应。

## 7. 无边框旁白与五秒节奏

### 7.1 视觉形式

旁白直接叠放在场景插画下部，用柔和的暗色渐变提高文字对比。边框、弹窗标题栏和底部的下一步按钮移除。说话者用小字号名称与正文区分，人物立绘在确有对白时出现。

主角自语采用第一人称，环境叙述采用旁白，NPC 对白保留人物名称。字体优先保证中文阅读清晰，正文建议保持在三至四行以内，长段按语义拆页。

### 7.2 翻页与点击约定

| 情况 | 交互 |
|---|---|
| 当前段已经完整显示 | 经过五秒自动前进，或点击旁白覆盖区域任意位置前进 |
| 当前段仍在逐字显示 | 第一次点击立即补全本段，再次点击进入下一段 |
| 进入新的一段 | 重新开始完整的五秒停留时间 |
| 最后一段结束 | 收起旁白，恢复场景调查 |
| 打开暂停或切换到后台 | 停止自动翻页，恢复后给当前段完整阅读时间 |
| 点击地图、背包或物件所在位置 | 旁白覆盖层接收该次点击，底层操作等待旁白结束后重新点击 |
| 键盘操作 | 空格或回车推进文字，保留明显焦点与可朗读正文 |

首次播放给出一次淡入淡出的“点击画面继续”提示。暂停与自动播放开关放在阅读设置中，回看入口放在日志中。剧情选项需要明确选择，自动翻页只处理文本和演出。

旁白覆盖区域指游戏内容视口。移动端点按按同一套规则处理，滚动和手势拖动不应被识别成连续翻页。

### 7.3 五秒的具体含义

五秒从一段正文完整显示时开始计算。逐字动画的耗时单独计算，玩家手动翻页后清理上一段的计时器。

动画、旁白、任务提示、线索整理和晋升卡片的阅读期间，世界时钟暂停。发生调查或移动等行动时，其游戏内费用在结算时统一写入。

## 8. 关键事件插画与猎人晋升卡片

用户参考图提供了清晰的信息层级，包含“成为非凡者”、途径序列、猎人名称、失控度、体力变化、技能和晋升风险。建议把这些信息用于插画演出后的结果展示，视觉使用项目现有的暗色海港风格。

### 8.1 晋升事件的顺序

1. 玩家在旧墙调查中主动选择接触，并获得危险预兆。
2. 插画展示墙体夹层、暗红结晶破裂与异常力量侵入身体。
3. 原剧本中的战鼓、马蹄、刀剑和耳语按旁白节奏播放。
4. 世界状态一次结算猎人晋升。
5. 显示晋升结果卡片，玩家读完后点击继续。
6. 返回电报局，血迹和环境提供猎人感知的新描述。

晋升卡片属于重大结果确认，建议持续显示至玩家主动关闭。这个建议区别于普通旁白的五秒翻页，避免重要数值和风险说明一闪而过。

### 8.2 卡片内容

| 层级 | 展示内容 |
|---|---|
| 事件标题 | 你成为了非凡者 |
| 身份 | 红祭司途径 · 序列 9 |
| 职业名 | 猎人 |
| 失控变化 | 显示晋升后的实际值，普通开局为 50% |
| 体力变化 | 上限 4 → 7，当前体力恢复至 7 |
| 解锁技能 | 猎杀直觉 |
| 技能解释 | 更容易察觉陷阱、追踪目标、分辨环境中的异常痕迹 |
| 风险说明 | 你异常吸收了封存于墙体内的猎人非凡特性，未经正规魔药晋升，污染与失控风险已经显现 |

失控条按实际状态绘制。若晋升前失控度已经高于 50%，保持较高值。卡片数据由本次结算结果填入。

“红祭司途径 · 序列 9”作为系统获得信息展示，随后标记知识已解锁。主角接触墙壁前的独白继续使用自己已经理解的词汇。

### 8.3 图片与资源需求

建议新增猎人觉醒专用插画，主体为墙中结晶、受侵入的手臂与战场幻象，文字由界面叠加。美术描述应体现封存特性与异常吸收的因果。

已有壁画图可以用于接触前的调查场景。觉醒插画需要单独制作并检查文件后登记，资源状态随实际交付更新。

同样的事件展示方式可用于发现壁画、错过客船、获救和毁灭结局。普通拾取使用简短物件反馈。

## 9. 技术结构与现有代码衔接

建议继续使用现有网页运行与 GitHub Pages 发布方式。重点建设地点、对象、知识和任务之间的规则关系，并沿用已有条件与效果解释器。

| 职责 | 现有内容 | 建议调整 |
|---|---|---|
| 世界状态 | 时间、属性、背包、旗标、已结算事件 | 加入地点内区域、对象状态、推理状态与任务阶段 |
| 条件和效果 | 场景选项及定时事件解释器 | 供地图移动、物件交互、证据出示和线索组合共同调用 |
| 剧情数据 | `data/scenes.json` 中的场景、对白、选项 | 保留稳定事件 ID，将可独立触发的段落按条件引用 |
| 地点与对象 | 当前以场景选项表示 | 数据描述连接、热点区域、物件位置及已调查状态 |
| 线索 | `data/items.json` 中的线索目录 | 补充来源、推理配方、核验结果和适用范围 |
| 界面 | `game/app.mjs`、`game/style.css` | 增加地图热点、对象操作、任务提示和推理页 |
| 旁白 | `game/narration.mjs` | 五秒完整停留、无边框覆盖、点击翻页及阅读暂停 |
| 保存 | 当前角色、事件与旁白播放记录 | 原子保存行动结果，恢复对象与推理状态 |

实现初期可在已有数据结构中明确分区。地点、推理和任务数据增长后，再按职责拆出独立文件。每一类数据均需有稳定 ID、可验证的引用和唯一结算记录。

### 9.1 主流水线

一次行动依次经过“取得输入 → 校验条件 → 计算时间与世界事件 → 生成结果 → 保存 → 播放演出”。输入可来自地图热点、对象面板、对话话题或线索簿。

演出只读取已提交的结果，重复播放不重复发放奖励。一次性奖励绑定事实或事件 ID，防止通过重复出示、换组合顺序或刷新获得额外收益。

NPC 回应依据可感知证据、过去互动和日程。玩家心中的未出示推测，不会自动变成 NPC 已知事实。

### 9.2 存档与版本

- 给新版存档明确版本号，保存所在地区、房内区域、对象位置和推理状态。
- 现有已获得的道具、线索、成就、死亡结局与已完成事件，应逐项定义新版映射。
- 新增窗帘观察与灯光试探等记录，通过实际事件获取。旧存档拥有灯笼不代表已经验证相关推理。
- 无法映射的旧存档问题应在实施与测试时明确列出，迁移策略另行决定。
- GitHub Pages 在仓库子路径下加载地图、立绘和事件插画，并通过真实浏览器验证。

## 10. 建议实施顺序

| 顺序 | 交付内容 | 完成标准 |
|---|---|---|
| 第一批 | 无边框旁白、五秒阅读、苏醒动画与初始任务 | 玩家能理解处境并顺畅开始调查 |
| 第二批 | 住宅地图、物件调查、取放与步行转场 | 通过点选区域和具体物件完成开场搜查 |
| 第三批 | 线索簿组合、事实与推测、灯光教学 | 从观察到组合再到实地核验形成完整过程 |
| 第四批 | 住所—旧街—餐厅—码头的状态驱动任务 | 两种调查顺序与两种证据组合可以推进交涉 |
| 第五批 | 电报局、壁画、晋升插画与卡片、外海推理 | 猎人路线的知识、条件和风险衔接完整 |
| 第六批 | 全幕回归与公开站点验收 | 地图、时间、人物日程、死亡与两条逃生路线协同运行 |

推荐先完成开场小范围版本，再把同样的交互方式扩展到整个第一幕。第一批至第三批即可验证用户提出的主要体验是否成立。

## 11. 验收清单

### 11.1 苏醒与任务

- [ ] 首次进入卧室时播放苏醒演出，原剧本关于名字、职业和记忆空白的内容得到衔接。
- [ ] 主任务《调查你失忆的原因》仅登记一次，跳过动画、暂停和刷新均能继续。
- [ ] 玩家可自由决定先调查窗帘、客厅、厨房或门口。
- [ ] 发现白玛瑙号后新增逃生任务，已有失忆线索仍可查看。
- [ ] 本幕的任务结算保留失忆原因和木箱真相的未解状态。

### 11.2 地图与物件

- [ ] 点击厨房进入对应区域，点击刀架后才出现水果刀的操作。
- [ ] 背包上限为两件，安全区域放下的道具能在其实际位置再次取得。
- [ ] 房内新布局、文字描述和插画物件位置相符。
- [ ] 去码头等地点通过地区地图完成，预计路程与到达结果一致。
- [ ] 步行演出可跳过，连点和刷新均不重复扣时或发放收益。
- [ ] 途中跨过船期或其他事件时，目的地与任务反映最新状态。

### 11.3 旁白与阅读

- [ ] 旁白使用无边框场景叠字，界面没有下一步按钮。
- [ ] 每段完整显示后五秒自动前进，手动推进后上一段计时器被清理。
- [ ] 点击旁白覆盖区域任意位置可前进，点按不穿透到下层行动。
- [ ] 逐字显示时第一次点击补全正文，之后再推进。
- [ ] 暂停、后台切换、日志回看和关键卡片阅读都不会推进世界时钟。
- [ ] 中文长段拆页后含义完整，移动端正文与关键控件可用。

### 11.4 线索与人物

- [ ] 线索保存来源和事实正文，推测能追溯到输入证据。
- [ ] 线索可以点击查看详情，获得线索时有明显提示。
- [ ] 两条灯光相关记录先形成推测，实地结果支持有限保护结论。
- [ ] 两条线索组合成功后原卡片消失，只留结果卡；结果卡继承原事实的对话用途。
- [ ] 组合顺序不影响结果，重复组合不复制条目或奖励，失败组合保留原卡片。
- [ ] 未进行组合的玩家仍能尝试普通交谈、直接使用物品和绕行。
- [ ] 条件对话须由已调查获得的线索解锁，NPC 仅回应已经出示或知晓的信息，同一事实不能重复增加信任。
- [ ] 船长透露格尔曼行踪后，才开放对应的寻找与介绍话题。
- [ ] 两条不同调查过程都可满足已明确的交涉条件，人物仍受日程和自身目标约束。

### 11.5 关键事件与硬规则

- [ ] 晋升演出明确展示封存特性被异常吸收，结算后显示实际属性。
- [ ] 猎人体力上限与当前体力均为 7，失控度至少 50%，猎杀直觉仅解锁一次。
- [ ] 晋升卡片在刷新后不会再次发放收益，玩家可查阅已经解锁的信息。
- [ ] 灯笼保护最多十分钟，同一路段反复点燃、切图和读档均不刷新保护。
- [ ] 手提灯可在可用火源处重燃，收费借火与两级付费交涉均先取得相应线索。
- [ ] 理智减少、失控增加使用醒目的有色文字及明确数字反馈，交易金额与物品同步结算。
- [ ] 第一夜电报局强闯仍触发死亡，离港后不能再登白玛瑙号。
- [ ] 猎人外海路线检查能力、航线、安全下海点、有效信号、体力与救援窗口。
- [ ] 失控、理智耗尽、毁灭和死亡封存规则能与新交互一起正常结算。

实施后的验证沿用 `python tools/validate_data.py`，并补充地点连接、物件引用、推理配方和任务状态检查。运行受影响的规则测试、构建或语法检查，并在真实浏览器中验证地图点按、旁白节奏、关键事件和公开子路径资源，检查前端异常及 HTTP 4xx/5xx。

## 12. 本稿建议采用的默认细节

以下为便于把需求落到实现而补充的设计判断，可在下一轮评审调整。

1. 房内采用卧室、客厅、厨房、门厅四区域，并把水果刀定位至厨房。
2. 房内短距离移动先按零游戏分钟处理，跨地区移动沿用明确的路程费用。
3. 线索组合使用两张输入卡，成功后替换为一张结果卡，继承来源事实与话题权限。
4. 新旁白五秒停留从全文显示完成起算，晋升结果卡片等待主动关闭。
5. 失忆主任务在第一幕取得阶段证据，真正原因继续保留悬念。
6. 灯光相关推理先作为有限假设，核验后写入短时保护规则。

现有剧本文件保存原文。后续实施时，将采纳的改写、物件位置调整及人物规则变化同步记入相应机制与验收文档，并逐项说明与旧设计的衔接。
