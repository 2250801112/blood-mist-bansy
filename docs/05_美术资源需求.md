## 画面风格

维多利亚时代海港、克制的哥特黑暗奇幻、冷灰雾气和低饱和深红，微弱煤油暖光构成视觉反差。界面图形简洁，无图片内嵌文字（文字在游戏 UI 中另外叠加，便于多语言/逐字效果）。避免将所有居民画成明显怪物：第一夜应只看到表情冷漠和动作僵硬。

## UI 需求

- 主菜单“开始游戏/继续游戏/成就/退出游戏”由 UI 字体渲染，不烘焙到背景图。
- 场景的时间、地区、理智、失控度、两格物品栏、线索簿可收起显示。
- 选项按钮统一样式，文案描述行动。玩家可根据环境与对白中的线索作判断。
- 主菜单的灰雾缓慢漂移。序章开始时，灰雾从暗处逐渐升起，港口轮廓随之浮现。
- 序章逐字显示并可跳过。按07新版节奏，正文与行动反馈以无边框场景叠字播放，全文显示后五秒推进一段，支持点击补全与翻页、暂停和回看；晋升结果卡等待主动确认。
- `assets/ui/` 后续放头像框、项目Logo、按钮贴图；首版允许 CSS 绘制。

## 程序约定

如果图片文件不存在，Codex 使用占位渐变背景和局部氛围效果；不要在数据或 README 中声称文件已存在。仅在实际文件落盘并核实后把 `data/assets.json` 的状态改为 `ready`。
