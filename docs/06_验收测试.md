# 第一幕验收与自动测试建议

## 最小功能验收

- [ ] 主菜单4项可操作；首次开始执行灰雾/文本演出。
- [ ] 启动脚本能打开菜单。跳过序章后，时钟仍为 22:17。
- [ ] 主菜单有缓慢漂移的灰雾，序章的雾从屏幕下方升起，结尾由红光照亮。开启系统的减少动态效果偏好后，灰雾显示为静态。
- [ ] 同组行动按钮用相同样式。无论出海条件是否齐备，崖边都只显示一个「下海」选项。
- [ ] 合法行动结算后显示无边框旁白，全文呈现后五秒翻页。点击先补全逐字显示，再次点击翻页。阅读设置、后台切换暂停翻页，覆盖层不把点击传给底层行动。
- [ ] 回看剧情可阅读当前场景正文和上次行动反馈。旁白播放、暂停及回看不消耗游戏内时间。
- [ ] 与堂娜交谈再回餐厅只弹出新的行动反馈。刷新续玩后再次回访，已播过的餐厅开场仍不会自动弹出。
- [ ] 堂娜和玛蕾娜各只能选一项回应。格尔曼的互斥答复会消失，信任降为负数后不再出现交谈入口。
- [ ] 格尔曼在 00:20–01:10 开放交谈。00:50 到访仍以 01:10 为截止，来不及连同追问一起完成的选项会消失。
- [ ] 00:25 厨房争吵与堂娜救援开始竞争时间。两件事都在 01:05 截止，先做一件会错过另一件，格尔曼仍按自己的时间离开。
- [ ] 菜单和场景加载本地插画；堂娜、格尔曼等角色开口时，场景叠字旁能看到对应立绘。
- [ ] 首次进入普通人、初始姓名可设置，初始非凡途径为空。
- [ ] 检查房间可搜到灯笼、刀、信、收据、晚餐和床下储物箱。22:35 仍在房内会被敲门打断，已经离开时仍留在街上。线索不占背包。
- [ ] 背包最多2件，超过时明确要求弃置/交换。
- [ ] 第一夜直接开门进入死亡D；保持安静能活。
- [ ] 无头异常的危险有文字/画面预警。
- [ ] 第一夜电报局强闯必死，隔门交谈能获得线索。
- [ ] 第二天电报局两人消失，只有两滩血迹，壁画调查可触发。
- [ ] 玩家接触壁画后成为序列9猎人，失控度至少50，获得能力。
- [ ] 格尔曼的每类信任奖励只能获得一次，60点且有证据才可担保。
- [ ] 客船离港后再也不能乘坐，玩家进入第二逃生路线。
- [ ] 没成为猎人不能靠普通游泳稳定逃出。
- [ ] 拥有猎人能力+外海船航线+安全路线+求救信号，可成功出海。
- [ ] 失控度到100立即结局F；72小时未逃生则结局C。
- [ ] 死亡后不能继续同一角色的早期检查点；成就图鉴保留。
- [ ] 场景不存在图片时 UI 不报错而是显示可读占位。

## 关键路径样例

### 路径A：正常人的逃生

苏醒 → 拓录收据 → 码头观察船员并组合引荐方案 → 付款引荐、听船长说明要求与格尔曼行踪 → 餐厅核验证据，或救下堂娜后出示收据 → 信任达到 60 且通过筛查 → 05:00–05:30 申请担保 → 处理玛蕾娜请求 → 在 06:00 前或恰在 06:00 完成登船 → 结局 A。高价安置的实际筹资路径见 `09_调查与交易落地记录.md`。

### 路径B：猎人的逃生

苏醒 → 错过客船 → 第二天电报局血迹 → 壁画异常吸收 → 猎人序列 9、失控 50 → 10:00–12:00 查港务记录 → 16:00–18:00 在灯塔调查并记录下海点 → 携带求救信号 → 1月11日 04:20–04:40 海上逃生 → 结局 B。

### 路径C：无作为

苏醒 → 重复消耗调查/等待时间但不逃生 → 第三夜22:17 → 结局C。

### 路径D：冒险开门

苏醒 → 听到门外异常对话 → 仍决定打开门 → 结局D。

### 路径E：夜闯电报局

苏醒 → 出门 → 第一夜电报局 → 强闯 → 结局E。

### 路径F：失控

第二天猎人晋升后 → 连续接触高危仪式/触发累积失控 → 100 → 结局F。

## 数据一致性

运行：

```bash
python tools/validate_data.py
node --test tests/game.test.mjs tests/act1-schedule.test.mjs tests/investigation.test.mjs tests/port-exploration.test.mjs tests/hunter-exploration.test.mjs
python -B -X utf8 -m unittest discover -s tests -p test_launcher.py
node --test tests/browser.test.mjs
```

必须做到：JSON语法正确、ID无重复、选项的`next`存在、人物和道具的引用存在、结局ID一致、资源缺失状态如实标记。

## 重点边界场景

- 登船需要 10 分钟。05:50 开始可在 06:00 准时完成，05:59 与 06:00 都来不及开始。
- 读取收据不占背包，携带两个实体道具时再次捡起第三件须阻止。
- 在电报局待到第二天不能通过“刷新灯笼”强行绕过第一夜即死规则。
- 同一格尔曼对话选项重复点击不应无限加信任。
- 玩家已达失控100，后续任何成功逃生剧情不可再触发。
- 没有必要美术文件时，所有页面仍然可用。
- 跳过开场CG后，时间不能被意外扣除。

## 07/08 改版自动验收

- 苏醒只登记一次任务，房内移动零分钟，厨房拿刀，安全地点的物品按实际位置取回。
- 原卡合并后从列表移除，来源和用途继承，交换顺序、共享事实的继续推演、重复发现均不复制奖励。
- 未得行踪消息隐藏格尔曼专属入口，未知收据话题隐藏；原始收据与复合卡都能核验，教堂证据组只奖励一次。
- 引荐8、借火2、安置120与实际事件同时结算；事实出售后保留知识，同一事实不能因组合换名再次卖。
- 未点燃的灯不能在街上凭空重燃。实际火源重燃后，原路段的警觉和保护截止点保留。
- 晋升卡等待确认，刷新继续，技能和属性只发一次。理智仅剩4时受击归零，实际变化提示为−4。
- 无头、电报局、失控、毁灭、A/B逃生及死亡封存继续通过规则回归。
- 真实 Edge 检查五秒停留、暂停、点击不穿透、线索详情、地图与取放、交易、晋升刷新、A/B及死亡、390像素宽度与 `/preview/` 静态资源。公开部署环境仍需在实际发布时验收。

## 全港探索与猎人后半幕验收

- 全港地图使用海岸与道路图，公开地点可选，未知下海点不提前显示。路径按实际道路计时，多段行程只提交一个回合；途中遇到必须处理的危险时停下。
- 初次离家不能通过地图跳过门口和街口。对话、追逐和登船期间不可借地图离场；路途中跨过06:00后不可恢复客船。
- 餐厅五区、码头四区及其他地点的区域按钮可操作。区域切换零分钟，跨区域行动拒绝执行，刷新保留区域；第一夜电报局不开放室内区域。
- 物品放下后留在实际区域，另一区域不能取回。版本2的落地物迁为地点遗留物；尚未调查的原始道具仍走调查流程，死亡不能借迁移复活。
- 主画面只有一个追踪目标；对话结束保留刚才人物的选择，已完成回应显示记录状态。线索卡有摘要、用途和状态，来源默认折叠，关联模式外不常驻复选框。
- 地图状态标注上次亲见时间，离开地点后不会按世界钟替玩家更新远处调查。06:00 主目标转为寻找其他离港方式，读告示不会直接得到灰鸥号时刻。
- 普通人能记录血迹和脚印，只有猎人能复查分析。H01–H05 均要求实际取得线索，不认定失踪者去向或木箱内容。
- 巡逻、掩体、观潮及记录共20分钟。17:40从头开始可在18:00完成，晚一分钟不可补记；关键路线体力消耗后仍至少剩5。
- 吊环及铜杯诱导须先取得现场证据与推理；铜杯必须实际携带，放置后只可现场取回。诱导仅提供一次绕行，不刷新灯光，不可复制材料。
- 安全休整每整小时恢复2点、上限封顶，不降低失控。世界事件或看顾结束时中断；提交前提醒已取得的时间线索，不泄漏未知机会。
- 临下海核对身体、航线、下海路线、实际信号物与时刻。未知项显示“尚未确认”；准备不足时先确认永久死亡风险，取消不改变回合。
- 真实 Edge 检查桌面及390像素地图、键盘选点、完整巡逻观潮操作、休整预览、危险下海确认、A/B与死亡；检查 console error 和本地资源4xx/5xx。
