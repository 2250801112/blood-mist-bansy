# 全港地图、场景分区与猎人后半幕改版设计

版本 v1.0 · 2026-11-18 · 待实现设计

本轮针对已上线第一幕的游玩反馈：住宅探索保留，其他地点补齐同样的空间探索；全港地图统一出行；场景、线索与任务突出重点；白玛瑙号离港后，以调查与生存并重的玩法接续逃生目标。项目负责人已选择“调查与生存并重”。

本稿中的新增观察、场景交互和能力应用属于游戏改编。原剧本正文、人物基本设定、现有两条逃生结局与时间锚点继续保留。下列验收项是后续实现目标，不代表当前版本已经具备这些功能。

## 1. 这轮要解决的问题

| 当前表现 | 玩家受到的影响 | 改版目标 |
|---|---|---|
| 住宅有四区域，码头、餐厅仍按人物和动作排列按钮 | 场景缺少空间感，探索方式不一致 | 每个主要地点有局部图、区域、热点和状态变化 |
| 地区移动仍依赖当前节点的“前往／返回”动作 | 不容易建立全港位置关系，操作往返多 | 点开全港图，选地点，经明确的路径前往 |
| 动作、状态、任务、线索共同占据长页面 | 主次不清，重要结果被淹没 | 主画面突出场景、一个当前目标与一个选中对象 |
| 线索卡排版相近，打开详情又重复大量正文 | 很难迅速知道哪条线索能帮助当前调查 | 卡面先显示关键事实和用途，来源与完整文本按需展开 |
| 离港后主要靠等待进入电报局、港务和灯塔窗口 | 后半幕像完成资格清单，猎人的变化主要表现为数值 | 明确阶段目标，让血迹分析、巡逻判断、诱导与观潮分别改变行动结果 |

推荐沿用住宅的“局部图＋区域＋热点”，各区域共用一套场景操作。另一种可行方式是每个小区域使用独立整幅插画，临场感更强，但资源量和首轮制作成本明显增加。本轮先用局部图建立完整探索，再逐步替换独立视角插画。

## 2. 四条核心体验

1. 出行：全港图 → 选目的地 → 看路程与风险 → 前往，途经实际道路并处理事件。
2. 探索：选区域 → 点眼前的人或物 → 查看相关的少量行动 → 得到有重点的反馈。
3. 推理：看当前问题 → 读关键线索 → 选择证据关联 → 通过现场行动核验。
4. 猎人生存：看见异常痕迹 → 使用猎杀直觉分析 → 比较证据 → 安排行动与撤离。

线索继续是条件对话的前置。空间上的人物入口不会自动开放玩家尚不知情的话题。组合后原卡消失，结果卡继续承载原事实、来源和用途。

## 3. 班西港总地图

### 3.1 地图上有什么

第一版制作可点击的二维港口示意图，画出海岸、街巷、居民区、码头与灯塔岬角。采用为游戏创作的布局，不将坐标标成经过原著确认的地理测绘。

| 地点 | 图上作用 | 首次可见范围 |
|---|---|---|
| 玩家住所 | 居民区起点、已确认的休整点 | 本地人熟悉的公开地点 |
| 血雾旧街 | 联结各区的道路，承载夜路遭遇 | 已知街道 |
| 青柠檬餐厅 | 交谈、人物事件、火源与后期回访 | 已知公共地点 |
| 电报局 | 第一夜隔门取证，次日进入调查 | 已知公共地点，内部状态需亲见 |
| 风暴教堂外围 | 委托现场与运输痕迹 | 只展示公开外部范围 |
| 港边货棚 | 交易、港口见闻、后期准备 | 观察到收货人后显示服务标记 |
| 白玛瑙号码头 | 引荐、筛查、最后登船；离港后为空泊位 | 船只状态随已知信息更新 |
| 港务值班室 | 公告与航运记录 | 知道地点不等于知道船期或能读到原件 |
| 旧灯塔 | 守灯人、信号物与观潮 | 地标可见，道路是否可通行由现场信息决定 |
| 右侧海湾下海点 | 猎人逃生的最后接近位置 | 发现实际下海点后才显示 |

地图使用“当前位置”“当前调查标记”“已发现服务”“玩家已经知道的关闭状态”。地图不得提前显示壁画、隐藏特性、未调查的巡逻盲区、灰鸥号时刻或未知人物去向。

### 3.2 出行方式

- 常驻工具栏只有一个“班西港地图”入口，替代散落在各节点中的普通前往和返回按钮。
- 点地图上的地点后，底部只显示地点名、预计耗时、已知风险，以及一个“前往”按钮。键盘聚焦同样能读到这些信息。
- 跨多个街区时，将途经点与总耗时列在同一处；玩家无需反复进入旧街节点才能继续点下一站。
- 路程沿数据中真实存在的连接计算。地图位置不产生瞬移，不用直线距离代替现有行动时间。
- 出发后逐段结算。遇到必须由玩家决定的危险便在遭遇点停下，解决后再决定是否继续。
- 06:00 离港、09:40 电报局变化、人物离场、记录关闭与毁灭照常发生。路途中越过事件时刻也要处理。
- 整理地图、查看路径不计游戏时间，提交移动后才结算。连点、刷新不能重复移动或恢复旧状态。

第一夜的灰雾序章、未离家的门外遭遇、危险追逐、正在登船和海上终局等状态只展示当前可达范围。玩家脱离受限状态后恢复全港出行。

### 3.3 日期变化要看得见

同一地图逐步呈现“船还在”“空泊位”“电报局门开了”“餐厅反锁”等玩家已经观察到的变化。未去过的地点可以显示“上次见到的状态”，并保留观察时间，避免地图替玩家完成调查。

格尔曼、堂娜、船长和船员离港后按日程离开。地图不会把他们作为永久功能入口留在原位。

## 4. 全场景采用分区探索

### 4.1 区域与热点清单

| 地点 | 局部区域 | 每区主要热点与作用 |
|---|---|---|
| 码头 | 岸上入口 | 告示、拦路船员、登船规则与首次拒绝 |
| 码头 | 登船栈桥 | 值班船员、艾尔兰、舷梯；人物随引荐与日程出现 |
| 码头 | 值夜棚 | 灯罩、借火人、等候位置 |
| 码头 | 海堤与泊位 | 白玛瑙号或空泊位、系缆桩、离港后的航务提示 |
| 餐厅 | 门厅 | 招待、窗边声音、离开餐厅 |
| 餐厅 | 餐桌区 | 堂娜、黑礼服旅客、可旁听的谈话；按日程出现 |
| 餐厅 | 柜台 | 玛蕾娜、值夜灯火、留物记录 |
| 餐厅 | 后厨 | 原有争吵事件、碗碟和工作痕迹 |
| 餐厅 | 后门 | 原有救援事件、通向侧巷的门、危险征兆 |
| 货棚 | 收货柜台、旧货堆 | 收货人、可见交易、取回已买回物品的交付处 |
| 电报局 | 门廊、窗口、工作间、旧墙 | 第一夜只开放门外安全调查；次日开放室内与壁画调查 |
| 港务室 | 外廊、公告栏、登记桌 | 交班告示、航线原件、公开抄录位置 |
| 教堂外围 | 正门、侧门、卸货道 | 委托痕迹、箱车路线与可撤离位置；不擅自开放教堂深层秘密 |
| 灯塔 | 入口、塔后、崖边、右侧海湾 | 巡逻、信号物、观潮与下海前准备 |

货棚仍是独立地点，地图和码头图用相邻位置表达关系。码头的值夜棚负责借火，避免把交易与借火再次挤成同一个功能菜单。

### 4.2 操作约束

局部图切区域沿用住宅规则，不扣游戏分钟。实际调查、交谈、拾取、布置和跨地区移动按行动计时。这样不会因为补上区域选择就破坏原有格尔曼、救援与登船窗口。

点区域后只看该区域的热点；点热点后出现该对象的短说明与通常不超过三个直接动作。另一个区域的动作不会挤进当前操作面板。交易按类别浏览当前报价，不把所有可卖物件直接铺在场景正文下。

关闭对话回到刚才的区域，保留选中对象；对象离开或已取走时显示实际变化。已经调查的热点只有出现新状态时再提示。剧情与动作被条件锁定时，仍遵守“先得到线索，再开放相应话题”。

## 5. 主页面突出什么

### 5.1 画面层次

从上到下固定为：

1. 简洁状态条：日期时间、体力、理智／失控与金钱；受损时短暂突出实际变化。
2. 一个正在追踪的目标：“确认下一艘船的消息”，下方只写一条来自已知线索的建议。
3. 大幅场景及局部区域入口，作为主要视觉焦点。
4. 当前热点的上下文操作卡，内容随玩家选择变化。
5. 工具栏：全港地图、线索簿、背包、日志。点击当前目标即可打开完整任务簿。

场景开场和行动结果继续用旁白演出。完整剧本、历次反馈和已完成任务收进回看与日志，保留原文与查阅能力。屏幕上同时只突出当前事件的一项主要反馈，连续数值提示进入队列。

### 5.2 内容显示限制

- 目标摘要最多两行，详细解释进任务详情。
- 热点短说明最多两至三行，完整观察正文通过旁白和详情阅读。
- 当前区域的可操作对象用位置或图标区分，避免把同一组文字按钮重新排列成“地图”。
- 理智损失、失控增加继续用明确颜色、正负号与文字，保证不依赖颜色才能理解。
- 原有两格背包在工具栏显示两个简洁物件位；完整说明与放下、取回放在背包面板。
- 五秒旁白、任意位置点击翻页、跳过步行、重大结果主动确认等既有行为保留。

## 6. 线索簿先显示价值，再显示全文

### 6.1 卡面示例

```text
灰鸥号航线                         已核实
明晨 04:30 · 经过灯塔外海 · 不入港
用途：寻找能接近它的下海点
港务登记桌 · 今日 10:18              查看详情
```

```text
守灯人的巡逻空档                   待现场验证
他转到塔后时，入口会短暂空出
用途：避开守灯人，接近崖边
来自：两次脚步观察＋泥地足迹          查看详情
```

卡面信息仅取自实际取得的内容。未读到航运记录时，没有上述船名、时刻和用途；没有确认巡逻规律时，不提前出现正确的行动窗口。

### 6.2 信息组织

- 默认显示“当前调查”，按正在追踪的任务关联已知线索，优先突出近期取得及尚待核验的关键记录。
- “全部线索”保留完整列表，可按求生、失忆、人物和异常筛选；已完成调查可以折叠，随时展开。
- 原始事实、待核验推测、核验结论、已过时信息使用不同状态标记与文字层次。
- 卡面只展示名称、最有价值的一句事实、已知用途和来源摘要。组合线索突出结论，原始事实仍可在详情展开。
- 详情先展示核心判断，再展示待核验问题；完整原文、来源与推理历史分别展开，避免同一正文重复出现三次。
- 普通浏览时不常驻全部复选框。点击“关联线索”后进入两卡选择，底部固定显示已选材料与一次关联操作。
- 不主动标出尚未推理出的正确配方。任务关联表示这条记录与问题有关，不等于向玩家公布组合答案。

组合、继续推演、重复出售限制、信任唯一记分、出售情报副本保留知识等现有机制不变。筛选、折叠和阅读均不推进世界时钟。

## 7. 白玛瑙号离港后的主线重新组织

### 7.1 离港时立即给出方向

保留原剧本“你被留在了班西港”的演出，并结算白玛瑙号机会永久结束。随后开启“寻找其他离港方式”。码头海堤与值班告示成为当前可调查对象。

新增告示只说明“外海补给船登记见港务室，航运原件在 10:00–12:00 交班期间可查”，由实际阅读取得。它不直接赠送灰鸥号船名与时刻。

玩家可以先追电报局的变化，也可以先查港务，再考虑是否接触旧墙。任务顺序依据玩家实际发现推进，拒绝异常晋升仍可调查其他地点，但不会获得猎人下海资格。

### 7.2 阶段目标与可执行内容

| 阶段 | 当前问题 | 能做的事 | 结果与下一步 |
|---|---|---|---|
| 06:00 离港后 | 还有别的船吗？ | 调查空泊位、读值班告示、回访餐厅或货棚 | 知道港务原件窗口，获得调查方向 |
| 09:40 后 | 电报局的人去了哪里？ | 在工作间比对昨夜记录与血迹，查看墙皮 | 触发原有旧墙调查，保留失踪原因的未知 |
| 10:00–12:00 | 怎样接近不靠港的船？ | 在登记桌读航线，抄录船期，与离港事实关联 | 得到灰鸥号航线，明白必须从灯塔外海接近 |
| 晋升后至观潮前 | 我的变化能帮我活下去吗？ | 重看血迹、辨认卸货道足迹、勘察塔前巡逻 | 学会在具体对象上应用猎杀直觉，得到局部行动方案 |
| 16:00–18:00 | 哪一侧能够下海？ | 利用巡逻信息接近崖边，观察两侧水流并记录 | 取得已有规则要求的安全下海点 |
| 第二夜 | 能否安全带着求救物到达海湾？ | 准备信号物、验证已知路线、安排遮蔽与诱导、休整体力 | 把原来的一次等待拆成有选择的出海准备 |
| 04:20–04:40 | 当前准备够不够？ | 在海湾检查实际物品、体力和最新海况，决定下海 | 沿用猎人 B 线的全部资格检查与终局 |

阶段目标不会提前揭示未发现的秘密。主角尚不知道非凡途径时，用“弄清身体的变化”描述，不用“去晋升猎人”引导。

### 7.3 等待仍然有意义

取消离港后必须一键跳至 09:40 才能继续探索的组织方式。06:00 后可以在已开放地点行动，电报局内部到 09:40 才能进入。

空档不靠重复十次低价值调查填充。玩家得到明确时间锚点并完成准备后，可以在已确认的安全地点选择休整至下一个时刻。提交前显示会跨过的已知机会；尚未查清的事件不提前剧透。

现有休息只推进一小时，没有恢复体力的效果。本轮建议明确增加安全休整：每完成一整游戏小时恢复 2 点体力，最多恢复至上限；不足一小时的部分不恢复。适用地点为访客已经离开且关好门的住所，以及收货人仍在并实际同意看顾的货棚。地点与看顾条件须现场确认，危险现场不可休整。

休整按真实耗时推进世界事件，地点失去安全条件时在相应时刻中断，只结算已经完成的整小时。休整不降低失控度，不刷新危险路段。阅读、剧情播放和现实中的等待均不扣游戏时间。

## 8. 猎杀直觉的五次实际应用

这些应用都归于现有 `hunter_instinct`，不增加新序列、凭空读心、预知过去或确定未知人物身份的能力。

### H01：晋升前后重新看同一处血迹

普通人观察：地上是两滩血，细长痕迹通向墙边。

猎人再调查：从喷射方向、拖擦覆盖与站位痕迹中发现不一致。主角只能提出“这里发生过不止一次移动”的判断，不能据此确定失踪者最终去了哪里。

建议新增内心文字：“刚才我只看见血。现在，连血落下的方向都像是在说话。”

作用：用一次可见对照教会玩家能力的用途，生成分析记录并更新失踪调查，不自动给出谜底。常规分析按短调查耗时，单次结算，不额外奖励属性。

### H02：辨认卸货道的追踪风险

普通人能记录潮湿脚印与箱车擦痕；猎人能比较落脚深浅、干湿和重复位置，发现有一段足迹在同一转角往返。

玩家结合自身亲见的响动，可推测该处有人反复经过，选择沿遮蔽物绕过或在原地观察，取得安全接近路线。此处只补充教堂外围的危险与运输关系，不认定木箱内容或玛蕾娜丈夫的身份。

作用：猎人用证据改变到达方式，普通人仍能取得表层线索。先有脚印和响动，才出现相应规避方案。

### H03：观察守灯人的巡逻

在塔前查看泥地与脚步，再用猎杀直觉比较两次观察，获得“他会绕到塔后”的推测。实际等待看到一次绕行后，才核验可接近入口的空档。

原先“观察潮汐并避开守灯人”拆为可理解的过程：发现巡逻 → 分析路线 → 选择掩体 → 在空档行动。观察和行动的总费用必须控制在原有观潮窗口内，不能因为增加点击就使 16:00 开始的合理路线失败。

第一轮用时建议为：查看足迹 2 分钟、观察脚步 2 分钟、分析规律 2 分钟、核验空档 3 分钟、掩体间接近 3 分钟，共 12 分钟。随后观潮 3 分钟、分析并记录下海点 5 分钟，共计 20 分钟。每一步继续校验完成时刻，最迟 17:40 开始该完整过程才能在 18:00 前做完。此前已完成的有效步骤可保留，不必重复支付。

### H04：布置声响，争取一次行动机会

玩家观察塔后松动吊环或现场可移动的旧物，获得声音传播的线索，再与巡逻记录关联，形成“把注意力引向塔后”的方案。

一种做法是利用固定吊环制造声响；另一种是把实际携带的铜杯放在现场可见的绳头上，借摆动制造干扰。物品放置保留位置与所有权，取回也需在实际地点操作。

声响只改变本次巡逻的位置和警觉，提供一次有限的绕行机会。守灯人不会被无害诱饵杀死；重复使用同一手段会失效或提高警觉，不能刷新原有灯光保护。

作用：物品既可以卖钱，也可以用于求生，玩家根据已知信息取舍。布置材料和线索缺失时，不直接给出完成方案的选项。

### H05：把海浪变成可判断的信息

保留原剧本：“左侧礁石下有暗流；右侧海湾相对平缓。你看出短暂的潮汐窗口。”

先让玩家在崖边看漂浮物、浪线和右侧回流，普通观察记录现象；猎人分析后才能在规定时段取得可靠下海点。结合实际航运记录与求救信号，生成完整准备方案。

临下海时呈现已经发现的准备项，缺少的信息显示“尚未确认”，不凭空列出玩家从未听说的标准答案。充分准备后按确定规则成功，不能再用随机数惩罚。

## 10. 能力代价与失败要让玩家理解

- 常规分析消耗明确的调查时间，结果只能首次取得，重复阅读不重复扣值。
- 强行追逐不可靠气味或长时间凝视污染源，可作为额外高风险调查，必须先说明精神负担并显示具体代价；主线安全路线不要求刷高失控度。
- 高失控时的冲动描述注明为主角感受，和已核验的物理证据分层展示。不会将幻觉悄悄覆盖成真实地图路径。
- 首次发现危险给出可以撤退的位置。玩家在明确征兆后继续强闯，才进入既有致命判定。
- 猎人可以更早发现埋伏、选择路线和节约体力；无头危险仍可一击致命，电报局第一夜强闯仍必死。
- 游泳继续要求序列 9、可靠船期、安全下海点、实际求救物、足够体力与正确时间，不能由一次直觉按钮取代。
- 正常完成的新增必经求生行动合计最多消耗 2 点体力，晋升后的 7 点仍可保留 5 点满足现有游泳门槛；自选冒险可能需要额外休整，预览时明确显示。
- 保留晋升初始失控度至少 50、体力上限 7、两格背包与死亡不可回溯。新增准备行动不能让正常完成的玩家在最后一刻无从得知为何体力不足。

## 11. 数据与状态的实现边界

复用现有条件／效果解释器、定时事件、`commitRun` 和旁白系统。界面负责呈现场景与对象，事实取得、路线耗时、危险和物品结算继续由引擎校验。

| 内容 | 需要明确保存或配置的部分 |
|---|---|
| 全港图 | 地点 ID、示意坐标、已知状态、真实路线、进入条件和当前阶段入口 |
| 地点分区 | 区域 ID、局部图位置、热点、当前区域、对象状态 |
| 任务摘要 | 当前阶段、玩家已掌握的下一步依据、可手动追踪的目标 |
| 线索展示 | 一句关键事实、状态、已知用途、任务关联和完整来源 |
| 猎人应用 | 实际前置、调查事件、分析记录、有限机会、耗时与失败位置 |
| 诱导与物品 | 现场材料、放置地点、已用机会、持续警觉和真实所有权 |

地区移动沿现有路线逐段执行，地图不另写一套条件判定。分区切换复用住宅的位置与保存方式，扩展至其他地点；区域化后，放下物品和发现火源也要保存到相应的真实区域。

旧存档进入新版时保留角色、事实、原配方、信任、交易、事件和死亡封存。新增区域只选择合理的到达入口，不补造玩家已经调查过的证据，不重新发放金钱、技能或线索。

区域化需要一次版本 2 → 版本 3 的迁移。场景是公开版本已有角色继续游玩；代价是新增一次性字段转换和迁移测试。旧记录若只知道物品在“餐厅”，继续标记“餐厅，旧版未记录分区”，在该地点的遗留物记录中取回，不能伪造原来放在了哪个房间。迁移成功后只运行版本 3 的正常逻辑，不建立长期的双版本执行分支。负责人确认不再接收版本 2 导入时，可删除迁移入口。这一兼容范围随本方案一并确认，未确认前不实现。

首版局部图与总地图采用可维护的二维布局。新插画如未制作，明确使用示意图，不将已有单视角图片冒充已经完成的新区域美术。继续使用轻量网页图片，避免再次引入大体积原图下载。
