# 第一幕调查与交易实施计划

**依据**：`docs/07_第一幕交互与叙事优化建议.md`、`docs/08_线索组合与情报交易设计.md`。

**目标**：在既有 JSON 解释器中接通住所调查、证据组合、两级交涉、交易与阅读演出，保留既有死亡和时间约束。

**边界**：不改原剧本正文与原著角色圣经，不新增依赖，不发布。格尔曼负信任永久拒谈按此前用户要求保留。可售空箱使用厨房独立旧包装箱，不决定床下储物箱内容。高价许可支付安置和看守费用，筛查与船期始终有效。
