# 全港探索与猎人玩法落地记录

2026-11-18 · 对应已确认的10号设计 · 本地第一幕原型

## 游玩方式

双击根目录的 `启动游戏.cmd`，或运行 `python tools/play.py --open`。本轮不提交、不上传、不部署，线上版本不会自动随本地文件改变。

主画面按状态、一个当前目标、场景、区域、眼前对象组织。地图、线索簿、背包和日志集中在底部工具栏。住宅四区域插画保留；其余地点先使用SVG区域图，港口总图绘出海岸与实际道路，属于游戏改编布局。

全港出行按道路寻找最短耗时路径，逐段处理世界事件；跨多个地区只结算一次操作。初次离家复用原有五分钟行动，在街口危险处停下。交谈、登船、追逐和终局不能用地图跳出。普通前往动作从主界面移到总图，原稳定ID继续保留。

地图上的地点状态记录亲见时刻，离开后不会按世界钟替玩家观察远处情况。公共地标可见，右侧实际下海点在确认安全路线后才出现。

## 后半幕内容

06:00后不再必须跳到09:40才能行动。海堤告示只透露港务原件查阅地点与10:00–12:00窗口，船名与时刻仍需实际抄录。主目标按取得的证据推进；直接查到航线也可继续，不强制补读告示。

| 应用 | 实际行动 | 保留的未知边界 |
|---|---|---|
| H01 血迹复查 | 普通记录、晋升后比较覆盖与喷射方向 | 不确定失踪者去向 |
| H02 卸货道追踪 | 脚印、响动、猎人分析与遮蔽绕行 | 不决定箱内物与人物身份 |
| H03 巡逻核验 | 泥地、两次脚步、推测、亲见核验、掩体接近 | 只提供局部接近方式 |
| H04 声响诱导 | 现场吊环/绳头与巡逻推理，固定吊环或实际铜杯 | 一次绕行，警觉保留，不杀死守灯人 |
| H05 观潮 | 崖边漂浮物与浪线、猎人分析、实际记录 | 不代替航线、信号和游泳资格 |

H03和H05从头开始共20分钟：2＋2＋2＋3＋0＋3＋3＋5。17:40开始可在18:00完成；此前有效步骤可保留。关键准备完成后至少剩5点体力供原有游泳行动使用。保留猎人由异常吸收封存特性而来、初始失控50、格尔曼独立行动、白玛瑙号不可追回等规则。

线索现共88张，包含R01–R24结果卡。原事实组合后收进结果详情，不复制卡片或奖赏；新用途文案只说明已知问题，不提示尚未推理出的正确两卡配方。完整原文、来源、推理和本轮新增行动反馈可在详情或日志展开。

安全休整需要实际确认住所，或取得营业中的收货人看顾许可。每整小时恢复2点体力，最高到上限；不足一小时不恢复，看顾结束或世界危险事件中断。休整预览给出实际预计耗时、恢复量及已知机会跨窗提醒。它不降低失控、不延长灯光保护。

临下海核对只显示已知身体、航线、路线、信号与时刻。没有确认的信息显示“尚未确认”。准备不足的冒险下海有明确永久死亡确认，取消不推进时钟。

## 内容与引擎约定

`data/scenes.json`新增`exploration.sites/routes`；地点有坐标、入口、默认区域、区域列表、现场状态描述及可选火源区域/营业时段。节点以`site`归属地点、`entry_area`定位演出所在区域、`map_locked`约束叙事阶段。行动沿用条件/效果解释器，新增`area`、`travel`和`rest`标记；住宅沿用`region`。

`known_windows`声明需要哪些已知事实才可提示时间机会。线索的`summary/use/topics`仅供分层阅读和筛选，不能代替取得线索的条件。

| 引擎接口 | 输出/作用 |
|---|---|
| `site/area/areas` | 当前地点、区域ID及可切换区域列表 |
| `moveArea` / `moveRoom` | 一回合、零分钟的区域切换 |
| `mapRoutes` | 已知目的地、路径、耗时、能否出行、原因及亲见记录 |
| `travel` | 逐段结算路线，遇到强制剧情中断 |
| `focus` | 单个当前目标、建议与相关的已取得事实ID |
| `timeWarnings` | 在指定时长内跨过的已知机会 |
| `seaReadiness` | 根据实际知识与状态生成下海核对项 |
| `describePlace` | 实际地点分区或明确标记未记录的旧位置 |

版本3保存`area_by_site`、实际放置物件`placed_items`及亲见记录`site_observations`。物品位置为`site:area`，实体容量仍两格；初次拾取继续执行剧本行动，放下或部署的已拥有物件才能直接取回。

已批准的一次版本2→3迁移保留金钱、知识、唯一奖赏、交易与死亡状态。旧版落地物若只记录大地点，保留为`legacy:site`当地遗留物，不伪造房间；未调查的初始道具仍在其编写位置调查。版本1先沿用原有迁移，再进入版本3；版本3重复恢复不再发奖。仅为接受现有旧存档保留这些导入逻辑，确认不再接收旧存档后可移除导入器。

## 验证与限制

验证命令见README和06号验收文档。本轮验证包含数据/区域/道路引用、原有规则回归、新增路线与物件、时间边界和真实Edge浏览器。浏览器使用实际页面，监测console与本地HTTP错误，覆盖`/preview/`仓库子路径、390像素、键盘选点、A/B逃生和死亡封存。

最终结果：64项规则测试、2项Python启动测试、1项包含完整交互链的真实Edge集成测试通过；JavaScript语法检查、JSON及地图数据校验通过，浏览器console与本地HTTP错误为0。浏览器额外核对了货棚看顾不足一小时的预览、18:00实际中断，以及冒险下海确认前不改变回合。

原始设计、完整剧本、世界观、NPC设定、人物与途径数据保持原文件内容；本轮新增观察属于游戏改编，不决定长期秘密。当前工作目录没有Git元数据，以开工临时基线对比改动并检查空白错误；未初始化新仓库。

本轮未加入精绘港口地图、各小区域独立插画、港务过期后的替代船期、第二幕或战斗系统。已过期机会仍真实失去，不以补送线索恢复。公开GitHub Pages环境须在实际发布时另外验收；本轮只验收本地与仓库子路径。
