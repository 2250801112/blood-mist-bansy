# 世界观与历史线：原著锚点、改编层、待核项

> 本文件将原著要素与游戏创作分开记录。当前包以已有对话为资料基础，**没有把对话中未经二次核实的日期当成原著定论**。制作公开发布版本之前应核对原著章节和细节。

## 原著世界观锚点（不应任意颠覆）

- 班西港位于《诡秘之主》的海上故事线；班西、旧宾西镇传统及异常污染存在深层联系。
- 格尔曼·斯帕罗是克莱恩使用的身份，具有独立行动目标，不是可随意雇佣的伙伴。
- 达尼兹、白玛瑙号的人员及风暴教会相关情节属于重要背景；游戏不能让玩家毫无代价改变原著角色身份与实力。
- “救赎蔷薇”及与壁画、古老秘密的关系是比序列9猎人高得多的隐秘层次；普通玩家早期只能得到模糊、未解的线索。
- 非凡晋升与魔药、非凡特性及失控风险有关。普通壁画不应无条件赐予能力。
- 《诡秘之主》里为“红祭司”途径、序列9“猎人”；避免误写为“红祭祀途径”。

## 第一幕改编事件（必须显示为游戏原创）

1. 玩家作为失忆的班西港杂工，从一场异常睡眠中醒来。
2. 由玩家本人写下的“不要让他们知道，我还记得”的未寄出信与教堂运输委托。
3. 餐厅服务员玛蕾娜·科恩，电报局职员梅兰妮和帕沃·考特，以及他们的变化。
4. 玩家在电报局旧墙下提前发现图案，并经隐藏非凡特性触发异常晋升猎人，失控度直接50%。
5. 名为“灰鸥号”的补给船、经过外海的航线和游泳逃生机制。
6. 72小时城镇毁灭结算（1月12日22:17）。
7. 格尔曼对玩家信任度的数值和“担保登船”的游戏化规则。

## 游戏内绝不能混淆的两类信息

- **玩家可感知**：阴冷的街灯、重复话语、血迹、陌生客船、教堂的收据、被遮蔽的墙画。
- **编剧/系统的上帝视角信息**：格尔曼的真正身份、救赎蔷薇、红祭司途径、非凡特性来源、毁灭时间安排。

正式文案中必须根据当前发现逐步解锁术语：未觉醒的玩家不能仅凭第一眼看到壁画就称它为“救赎蔷薇的壁画”。可在成就、档案和后续章节揭示。

## 正式发布前待核对事项

- 白玛瑙号第一次班西停泊的**精确日期与离港时点**。
- 班西饭店、人物称谓、具体目击事件与原著情节的顺序。
- 教会行动、班西港毁灭发生的确切日期与政治/非凡背景。
- 电报局壁画在原著中的确切发现者、发现时间和原图细节。

以上未核事项不妨碍作为同人游戏原型，但公开描述时必须表明是“改编时间线”。
