# 项目总览：血雾班西

## 游戏定位

- 类型：文字冒险 / 悬疑调查 / 克苏鲁惊悚 / 生存 / 非凡者成长。
- 操作：点击式场景与对话选择，当前**不考虑自由移动**；未来战斗为回合制、技能点击式。
- 核心循环：察觉异常 → 提出假说 → 搜集和交叉验证证据 → 承担时间与精神成本 → 作不可逆选择 → 进入分支结果。
- 情绪：不安、怀疑、共情、求生，不以频繁跳吓代替悬疑。

## 项目负责人提供的长期方向

1. 世界以《诡秘之主》为模板，存在22条神之途径。
2. 人物起点为普通人，经由事件获得非凡晋升机会；魔药配方可简化，序列4之前每次晋升可聚焦该序列一项代表性能力。
3. 世界事件按地点、时间发生；NPC也会成长、失控、死亡或改变立场。
4. 知识既是价值高昂的资源，也会构成风险。
5. 角色长期目标多样：追求真神可以是一类目标，保护人、寻找过去、报仇或寻找秩序也可成为有力度的动机。
6. 封印物有正面用途和负面代价；技能可以改变行动次数或回合规则。命运类能力可有特殊机制。
7. 不支持随意读档回溯；死亡或重大决定具有持续后果。

## 第一幕目标（本包范围）

- 让玩家在未知规则下活过第一个夜晚，发现班西人的异常。
- 给出“白玛瑙号清晨离港”这一清晰且紧迫的主目标。
- 利用青柠檬餐厅的对话、教堂委托与异变目击证据建立与格尔曼的互动。
- 允许错过安全船后，在第二天冒险成为猎人，以极高风险从外海获救。
- 让玩家体会：重要NPC有独立时间表，不会停下来等玩家。
- 以未寄出的信、教堂箱子和被遗忘的旧事作为后续章节的长线钩子。

## 人物设定

玩家可自定姓名/性别；职业与本地身份首版固定为港口杂工。玩家不预知非凡术语；在获得相应知识之前，对话不能突然展示“红祭司”“救赎蔷薇”等上帝视角概念。

## 时间与范围

- 起点：第一夜，1350-01-09 22:17（**暂定开发锚点；原著精确纪日待正式复核**）。
- 白玛瑙号：1350-01-10 清晨离港，游戏暂定 06:00 锁定登船。
- 电报局职员：第一夜存在；次日上午消失（游戏原创实施）。
- 灰鸥号：1350-01-11 04:30 经过外海，游戏原创船舶。
- 终局：1350-01-12 22:17 为玩家72小时毁灭结算，**明确属于改编**。

## 第一幕结局

- A《黎明之前》：登白玛瑙号离开；可仍是普通人。
- B《猎人与海》：成为猎人后成功抵达补给船。
- C《被历史吞没的人》：时间耗尽毁灭。
- D《人头灯笼》：被无头异变者袭击。
- E《门的另一边》：第一夜强闯电报局。
- F《最后一个猎人》：失控度达到100。

## 开发边界

第一版只实现红祭司途径序列9“猎人”的晋升；22条途径是未来框架，不需要在第一幕一次性做完。优先剧情可信、条件可检查、数据可维护，再考虑战斗系统和复杂美术演出。
