# 《诡秘之主：血雾班西》

> 第一幕《今夜，请不要开门。》｜离线文字冒险原型
>
> 基于《诡秘之主》世界观的非官方同人游戏。游戏采用改编时间线。

## 在线游玩

[打开《血雾班西》第一幕](https://2250801112.github.io/blood-mist-bansy/)。可直接将此链接发给朋友，无需安装或保持本地电脑开机。

进度保存在各自浏览器中，换设备或清除站点数据后不会自动同步。

## 开始游戏

Windows 上安装 Python 3.10 或更新版本后，双击 `启动游戏.cmd`。也可以在项目目录运行：

```powershell
python tools/play.py --open
```

在 Edge 或 Chrome 中打开 [本地游戏](http://127.0.0.1:8000/)，游玩时保持启动窗口开启。游戏可离线运行，无需安装第三方包。若端口被占用，可用 `python tools/play.py --port 8001 --open` 启动。请用同一浏览器、同一端口继续既有存档。

若旧版游戏还在运行，先在原启动窗口按 `Ctrl+C`，再双击启动脚本。浏览器未自动打开时，可手动复制启动窗口中的地址。

点击行动才会推进游戏时钟。每次行动自动保存，存活的角色可从主菜单继续。结局将封存角色，开始新轮回时可保留成就与结局图鉴。游玩记录保存在当前浏览器的本地站点数据中。

## 旁白与声音

- 旁白无边框叠在场景上。全文显示后停留五秒，再自动前进。逐字显示时点击先补全文字，再次点击翻页；空格与回车同样有效。「阅读设置」提供暂停和上一段，切到后台也暂停翻页。
- 同一轮中，同一场景的相同段落只自动播放一次。回访时可用「回看剧情」阅读当前场景正文和上次行动结果。翻页或回看期间，游戏时钟暂停。
- 玩家对堂娜和玛蕾娜各只能选择一次回应。格尔曼在 00:20–01:10 出现于餐厅，信任首次低于 0 后关闭私人交谈与担保请求。来不及完成的行动会从界面消失。
- 序章可以跳过。点击主菜单的「开启声音」可听见环境风声及序章的两声钟响。
- 苏醒后获得失忆调查任务。住宅分卧室、客厅、厨房、门厅，先选区域和物件再行动，水果刀位于厨房。房内移动不扣游戏分钟，调查和取物计时，步行演出可点击跳过。
- 线索可打开详情、选两张组合或在结果卡中继续推演。组合后原卡归入结果，来源事实与对话用途保留。通过「任务」「日志」查阅进展和实际属性变化。
- 先从码头取得引荐与船长的行踪消息，才可在餐厅辨认格尔曼。港边收货人买旧物及情报副本，同一事实只付款一次。灯必须在实际火源处点燃，同一路段最多十分钟的掩护不会因重燃刷新。
- 猎人晋升有专用插画与结果卡，等待主动确认；刷新不会重发属性与技能。更详细的改版范围和完整筹资试跑见 [07/08 落地记录](docs/09_调查与交易落地记录.md)。

## 验证

```powershell
python -X utf8 tools/validate_data.py
python -B -X utf8 -m unittest discover -s tests -p test_launcher.py
node --test tests/game.test.mjs tests/act1-schedule.test.mjs tests/investigation.test.mjs
node --test tests/browser.test.mjs
```

规则测试使用 Node.js 22，游玩只需要 Python 和浏览器。最后一条浏览器验收命令还需要 Windows 上安装 Microsoft Edge。规则测试覆盖两种担保组合、高价筹资和猎人逃生、时间边界、死亡、失控、物品位置、证据合并与交易唯一结算。

可用 `python tools/play.py --base-path /preview/ --port 8001` 在本地模拟仓库子路径。网页可直接从仓库子路径读取静态数据与素材，GitHub Pages 从 `main` 分支根目录发布。上传后应确认部署提交，并在公开地址检查页面、数据、插画和实际交互。

场景图和对白立绘均随游戏离线加载。文件及生成说明见 [美术资源](assets/README.md)。维护资源时按 `data/assets.json` 中登记的路径放入 PNG，并刷新页面。

## 制作原则

1. **保留用户规则**：普通人开局；22 条途径作为世界系统蓝图；序列四以前每级优先解锁一个代表性能力；回合制战斗是后续框架；知识有价值也有风险；人物和事件随时间独立推进。
2. **原著与改编分层**：原著人物与世界设定应谨慎使用。游戏独有 NPC、补给船、72 小时毁灭倒计时、壁画提前暴露等明确标注为改编。
3. **只做第一幕首版**：不擅自添加第二幕、不替用户决定全部世界终局。
4. **危险要有预警**：即死可以存在，但必须有充分的前置迹象与合理的因果，不应为了惩罚点击而随机杀死玩家。

## 第一幕的范围与待办

- 第一幕包含白玛瑙号与猎人外海两种逃生方式、A–F 六个结局和独立的海上遇难结局。白玛瑙号可走证据担保或额外安置付费申请；两者均受污染筛查和 05:00–05:30 申请窗口约束。登船耗时 10 分钟，最迟须在 06:00 完成。
- 运行时沿用原剧本的主要场景文案和对白。交互所需的部分提示与结果文本，例如街巷告警、出海失败和理智耗尽，补写在场景数据中。理智耗尽暂记入 C 结局，显示专用死因。
- 住宅使用可点击的四区域插画，区域视图取自对应象限，另有苏醒和晋升插画；地区地图展示当前位置与可用连接。各房间独立视角精绘、港务过期后的替代情报、玛蕾娜怀表后续、回合制战斗及其他途径留待扩展。
